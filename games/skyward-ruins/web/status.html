このページについて

ゲーム本体は Unity（6000.0 LTS・URP・WebXR Export）で作っています。このページは遊べるゲームではなく、Unity 版を公開するまでの制作状況です。 下の画像は、Unity とは別の確認用の描画（ゲーム論理の C# とドット絵・3D モデルを重ねたもの）で撮った写真で、Unity での表示そのものではありません。

Unity のビルドには Unity のライセンス（無料の Personal で可）が必要です。クラウドの作業環境で Unity Editor 6000.0.64f1 の起動までは確認しましたが、 ライセンスが未設定のためビルドは止まっています（「No valid Unity Editor license found」）。

2D アーケード（論理画面 224×288）

ボットが実際のエリアデータで遊んだ場面を、ドット絵で合成。地表は 16 エリアとも同じ描画規則で、森・草原・川・砂地・道路・基地・地上絵を描き分けています。

3D（斜め見下ろし）

同じ場面を立体モデルで再構成。照準は地上の着弾面に置き、要塞のコアが開いた瞬間が爆撃のチャンスです。

16 エリアの地表（縮小・下が開始地点）

赤＝地上物、黄＝隠し対象（オベリスク・旗）、紫＝大型要塞。地形・敵の組み合わせ・要塞・発見要素がエリアごとに違います。

キャラクター（独自デザイン）

音（すべて新規に合成）

32 サンプル×4bit の波形表を読む 3 声＋ノイズの独自シンセで作った WAV です。原曲・原音は使っていません。
