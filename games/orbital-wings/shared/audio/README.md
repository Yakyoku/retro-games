# ORBITAL WINGS の音

1985 年ごろの業務用横スクロールシューティング基板の**音源のつくり**をまねた、ブラウザで動くソフト音源です。
曲はすべてこの作品のために書き下ろしたものです。**元になったゲームの曲（旋律）は著作権があるので、写していません。**
まねているのはチップの構成と、当時の書き方（明るい矩形波の旋律、波形メモリのベース、PSG のアルペジオ、ノイズの打楽器）だけです。

## つくり

| ファイル | 役目 |
|---|---|
| `chip.js` | 音源の本体 `ChipSynth`。ブラウザ API を使わないので Node でも動く（テスト・書き出し用） |
| `mml.js` | 曲の記法を tick 単位のイベント列に変換 |
| `songs.js` | 曲・音色・波形・打楽器（記法の説明はファイル先頭） |
| `sfx.js` | 効果音（フレームごとのレジスタ書き込み手順）と優先度 |
| `worklet.js` | AudioWorklet。`chip.js` を相対 import してオーディオスレッドで回す |
| `audio.js` | ゲームから使う窓口 `AudioEngine` |

- **PSG-A**（AY-3-8910 相当: 矩形波 3 + 共有ノイズ + エンベロープ）と **波形メモリ 2 音**（K005289 風: 32 サンプル × 4bit）が曲、
  **PSG-B**（もう 1 個の AY-3-8910）が効果音専用。効果音が曲の音を奪うことはない。
- PSG のクロック 1.789772MHz / 16 で内部を回し、12bit 周期・5bit ノイズ周期・17bit LFSR・AY の対数音量表・ハードウェアエンベロープを再現。
  2 段ローパス（約 8kHz）＋間引き → 直流カット → ピーク抑え、の順に通すのでギラつかず、割れない。
- 曲の進行は 1/60 秒ごと（当時のドライバと同じフレーム単位）。同じ操作なら毎回同じ音になる（決定的）。
- **既定はモノラル（左右同じ）・残響なし**の「忠実」モード。`setArrange(true)` で軽い左右の広がりとエコーだけ足す（既定は切）。

## ゲームからの使い方

```js
import { AudioEngine } from './shared/audio/audio.js';
const audio = new AudioEngine();
startButton.addEventListener('pointerup', () => audio.unlock()); // 最初の操作の中で
audio.playMusic('stage1');   // unlock 前でも覚えておき、unlock 後に鳴る
audio.sfx('shot');           // 1 回の斉射につき 1 回（オプションの数だけ呼ばない）
audio.setPaused(true);       // 曲の進行を止めて消す。解除すると同じ位置から
```

オプションの弾は音を足しません。`option_shot` という音は無く、0〜4 個のオプションが一緒に撃っても `shot`（`double` / `laser`）を 1 回だけ鳴らします。
音源側でも、同じフレームに同じ効果音を何度呼んでも 1 回分になります。

## 曲の足し方

1. `songs.js` の `SONGS` に 1 曲足す（`tempo`・`loop`・`tracks`）。ループする曲は全トラックの同じ小節の頭に `L` を置く。
2. 小節ごとに `|` を書くと、1 小節がちょうど 96 tick か点検される。
3. `node --test tests/audio.test.js`（長さ・ループ点・音域・クリップ）と `node tools/render-audio.js --only <id>`（WAV と数値）で確かめる。

## 試聴用の原盤

`node tools/render-audio.js` で `audio-masters/` に全曲（ループ曲は前奏 + 2 周）と全効果音を書き出します。
音は 44100Hz で作って数値を点検し、ファイルは小さくするため 22050Hz モノラル 16bit の WAV（＋ ffmpeg があれば .ogg）で書きます。
`--rate 44100` で 44100Hz のまま書けます。ゲーム本体はこのファイルを使いません（その場で合成します）。
