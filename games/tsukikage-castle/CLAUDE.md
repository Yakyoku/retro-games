# CLAUDE.md — 月影の魔城（games/tsukikage-castle/）

この作品は Claude（Claude Code のクラウドセッション）で制作しました。決定事項・判断ログ・未解決をここに残す（次のセッションはまずこれを読む）。

## 目的
1985 年アーケード版『魔界村』の怪奇性・ユーモア・明快なアクションを参考にした**非公式の新規作品**を、
2D Web 版（デスクトップ・タブレット・スマホ）と 3D / VR Web 版（通常ブラウザの三人称 3D ＋ Quest 3 WebXR）で作る。
原作のキャラクター・絵・楽曲・面構成は再現しない。対象は大人（PROCESS.md §9 は適用しない）。

## 構成の要点
- `shared/core.js` が唯一のゲームロジック（60Hz 固定・決定的・描画に依存しない）。2D と 3D はこれを描くだけ
- `shared/stages.js` の Builder でタイル格子（0 空・1 固い・2 片側足場・3 はしご・4 溶岩・5 水）と敵・アイテム・移動床・炎の柱・中間地点・ボスの間を組む
- `tools/reach.js` が実際の core で到達探索 → ステージを直したら必ず `node tools/reach.js` と `node --test tests/*.test.js`
- 画面遷移・メニュー・保存・入力は `shared/app.js`（2D/3D 共通）。HUD・メニューは `shared/ui.js` が Canvas に描く（3D 通常は重ね、VR は板に貼る）
- 骨格ポーズは `shared/anim.js`（2D の art.js と 3D の models.js が同じポーズを使う）。歩幅 STRIDE = 4·脚長·sin(振り幅) で足が滑らない

## 判断ログ
- 2026-11-12 依頼文に作品フォルダの指定が無かった。ルート README の「gothic-platformer / ASHEN KNIGHT」枠は別セッションの予定作と衝突しうるので、新しいフォルダ `games/tsukikage-castle/` にした
- 2026-11-12 Unity Editor・ライセンスがコンテナに無いことを確認し、依頼書の切り替え条件に従い Web 構成（Canvas 2D ＋ three.js r187 WebXR ＋ Web Audio）にした。依存の追加なし
- 2026-11-12 TypeScript は導入しなかった（リポジトリ共通の「ビルド不要・CDN なし」構成を優先）。型検査は未実施として記録
- 2026-11-12 原作の録音・楽曲は参照も同梱もしない。全曲・全効果音を新規に作った（原音忠実モードなし）。制作者は音を聴けないため聴感確認なし
- 2026-11-12 音源は VOIDBLOOM の自作 FM 音源を複製し、矩形波 3 声を追加、残響を削除（依頼書の「過剰なリバーブを加えない」）
- 2026-11-12 ステージの寸法は跳躍性能（頂点 1.69u、水平 3.0u）から逆算し、到達探索で全ステージ「無傷・通常操作」でボスの間まで行けることを確認。最初の版は塔の段差 +3u・穴幅 6u などで到達不能だったのを直した
- 2026-11-12 稼ぎ防止は「中間地点を通った時点の得点・撃破記録・取得記録の写し」に戻す規則で一貫させた。湧く亡者は区間ごとの上限付き、湧いた敵は武器を落とさない
- 2026-11-12 3D はキャラクターを z=0 の面で動かし、地形は奥行き 2.6u の箱。VR では箱庭の 4 面を材質ごとの切り抜き面で切る（renderer 全体の切り抜きだとコントローラーまで切れるため）
- 2026-11-12 Quest の負荷: 静的な飾りを材質ごとに結合（描画回数 334 → 削減）、点光源は 3 つを近い光源へ割り当て
- 2026-11-12 検証で見つけて直した不具合: 短いキー入力の取りこぼし（tapped で 1 フレーム保持）、ポーズを開いた Start が押し直し扱いになりポーズが点滅（releaseAll で押下中扱いに）、難易度変更でメニューのカーソルが先頭に戻る、VR のレーザーが無効な項目を選ぶ・スティックの選択を上書きし続ける、無敵デバッグで穴から天井へ戻る
