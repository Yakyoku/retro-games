# Meta Quest 3 で遊ぶ（単体のブラウザだけで開始）

1. Quest 3 をかぶり、**Meta Quest Browser** を開きます。
2. アドレス欄に次の URL を入力して開きます。
   https://skyward-ruins-cloud-yk.netlify.app/
3. 読み込みが終わったら「はじめる」を押します（音が有効になります）。
4. タイトルで「**VR を開始**」を選びます（右上の「VR を開始」ボタンでも可）。許可を求められたら「許可」。
5. 座ったまま、目の前の卓上に戦場が見えます。メニューは**右手のレイを向けて右トリガー**で選びます。
6. 操作：**左スティック＝移動、右トリガー＝対空、左トリガー＝対地**、B ボタン＝メニューで戻る。左利きの人は設定の「利き手」で左右を入れ替えられます。
7. 見え方の調整：一時停止 →「設定」で「VR 盤面の大きさ」「VR 周辺減光」「3D の視点（斜め見下ろし／コックピット）」。正面がずれたら一時停止 →「視点リセット」（Quest の Meta ボタン長押しでも可）。
8. やめるとき：一時停止 →「VR を終了する」。

注意：2026-11-12 時点で、この URL は **Unity 版がまだ公開されていない制作状況ページ**です（Unity のライセンス設定待ち）。Unity 版を公開した後にこの手順で遊べます。Quest 実機での動作は未確認です。
