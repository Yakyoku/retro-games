# 音源一覧・イベント対応表・出典（鉄骨レスキュー）

この作品は Claude（Claude Code のクラウドセッション）で制作しました。

## 方針と区分
- **原作（1981 年アーケード版）の音は再現していない。** 既存作品の曲・効果音の複製は著作権の都合で行わず、
  「短く覚えやすいフレーズ・2〜3 声・四角波（12.5/25/50%）と三角波とノイズ・残響なし・固定音程」という
  当時のアーケードの作法だけを踏襲して、すべて自作した。
- 原音との A/B 比較は**未実施**（参照音源を取得・試聴していない）。したがって「原音忠実再現済み」の音は 1 つもない。
- 区分: すべて **自作（端末内合成）**。録音素材・外部音源・有料 API は使っていない。
- 試聴: クラウド環境では音を聴けないため、**実際の試聴は未確認**。確認済みなのは「曲データの拍数がそろう」「音域」「主要イベントに音が登録されている」（tests/audio.test.js）と、ブラウザーで例外が出ないことだけ。

## 仕組み（shared/audio/）
- `mml.js` 自作の MML 解析。`songs.js` 曲（MML）。`sfx.js` 効果音（区間の列）。`audio.js` Web Audio で合成・再生
- 系統（曲・効果音・追加の環境音）ごとに音量を分け、設定で調整・無効化できる
- 効果音は「系統」（main / hit / enemy / ui / move）ごとに優先度で割り込む（同時発音を抑え、当時のように声を取り合う）
- 確定イベント（ジャンプ開始・命中・ミス確定・クリア）でだけ 1 回鳴らす。論理側のイベントが 1 回しか出ないことはテストで確認
- VR: 位置に意味のある音（敵・樽・装置・危険）は PannerNode（HRTF）、曲・結果音は頭の向きに依存しない。危険音は距離で弱めすぎない。設定で 2D と同じミックスにできる
- iPad / Quest: 最初の操作で AudioContext を開く。画面が隠れたら停止、戻ったら再開
