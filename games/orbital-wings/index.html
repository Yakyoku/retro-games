カプセルを集めてゲージを進め、自分で装備を選ぶ横スクロールシューティング。最大 4 機のオプション、地上を走るミサイル、切り替えるダブルとレーザー、前方を守るシールド。火山から機械要塞まで全 7 ステージ。

2D · DESKTOP / iPad

2D 版で遊ぶ

正面から見る横スクロール。実解像度のベクター描画で、4K の大画面でもにじみません。

  • キーボード: 矢印 / WASD 移動・Z / Space 射撃・X / Shift パワーアップ・Esc 一時停止
  • ゲームパッド: 左スティック / 十字・A 射撃・B パワーアップ・Start
  • iPad: 左半分をなぞって移動、右のボタンで射撃とパワーアップ（同時に使えます）

3D · META QUEST 3 · WEBXR

3D 版で遊ぶVR 対応を確認中

立体の戦場を上下左右と奥・手前に飛ぶ。Quest 3 のブラウザーでは「VR で遊ぶ」から没入表示に入れます。VR 非対応の環境でも通常画面で同じ 3D 戦場を遊べます。

  • Quest 3: 左スティック 移動・右スティック上下 奥/手前・右トリガー 射撃・右 A パワーアップ・右 B 一時停止
  • 通常画面: 2D 版と同じ操作＋ E 奥 / Q 手前（ゲームパッドは右スティック上下）

遊び方

指定の編隊を全滅させるか赤い運搬機を倒すとカプセルが出ます。取るたびに下のゲージの選択が SPEED → MISSILE → DOUBLE → LASER → OPTION → SHIELD と進み、パワーアップのボタンで選択中の装備を得ます。 難易度は EASY / NORMAL / ARCADE。練習モードは本編で到達したステージから始められ、記録は本編と分けて保存されます。
