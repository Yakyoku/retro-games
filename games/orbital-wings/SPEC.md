# SPEC.md — ORBITAL WINGS 仕様

仮称 **ORBITAL WINGS**、プロジェクト識別名 **GradiusInspired_Cloud**、作品フォルダ `games/orbital-wings/`。
初代アーケード版グラディウスに着想を得た**非公式**の横スクロールシューティング。名称・機体・敵・ボス・地形・曲・効果音はすべて新規制作。

区分: **【確定】** 依頼で確定した要件／**【仮定】** 依頼の「推奨する初期設定」または制作側の判断（原作の実測値ではない）／**【実測】** このリポジトリのテスト・計測で得た値。

## 1. 対象と構成
- 【確定】2D Web 版（デスクトップ・iPad）と 3D WebXR 版（Quest 3 単体のブラウザー）。3D 版には VR に入らない通常画面の入口。
- 【変更・依頼者承認済み】エンジンは Unity の予定だったが、クラウドで Unity Personal を有効化できない（ENVIRONMENT.md）ため、**three.js r187 ＋ WebXR Device API ＋ Canvas 2D** で実装。
  ゲームのルールは描画から独立した 1 つのモジュール（`shared/game.js` ほか）で、2D・3D が同じものを使う。
- 【確定】公開: 本作専用の新規 Netlify サイト。`/` 入口、`/2d/`、`/3d/`。

## 2. 基本ルール
- 【確定】ゲージ順 SPEED → MISSILE → DOUBLE → LASER → OPTION → SHIELD。カプセル 1 個で 1 つ進み循環。決定で取得し未選択へ戻る。
- 【確定】未選択・取得不能・上限では消費せず、短い表示で理由（例「スピードは最大です」「シールドが残っています」）。
- 【確定】DOUBLE と LASER は切り替え（同時装備なし）。ミサイル・オプション・シールド・速度とは併用。
- 【確定】オプション最大 4 機。自機の移動履歴を **tick 単位**で追う（動いた tick だけ記録、止まるとオプションも止まる）。描画 FPS と無関係。
- 【確定】シールドは**前方**の攻撃を耐久分だけ防ぐ。地形・ボス本体・壁は防がない。残っている間は重ね取り不可、壊れたら再取得可。
- 【確定】判定は自機・敵・双方の弾・地形・シールド・ボス部位で分離。弾はすべて**掃引判定（線分と球）**ですり抜けを防ぐ。
  シールドで止めた弾は消えるので本体へ二重に当たらない。撃破は `dead` を見て 1 回だけ加点。被弾した瞬間に `alive=false` にして 1 回で 1 機だけ減る。
- 【確定】難易度 EASY / NORMAL / ARCADE。記録キーは `版:難易度:本編/練習`（例 `3d:arcade:main`）。練習は本編の記録に入れない。
- 【確定】多段 HP 制なし（1 ミス = 1 機）。

## 5. 画面・操作
- 【確定】トップ → 2D/3D → タイトル（押して開始で音声を有効化）→ 難易度・本編/練習 → プレイ → 結果 → もう一度／タイトル。設定・操作説明・クレジット。一時停止（再開・設定・操作説明・タイトルへ）。
- 2D: 矢印/WASD・Z/Space・X/Shift・Esc。ゲームパッド（standard 配列）左スティック/十字・A・B・Start。`id` から Xbox/PlayStation/Nintendo 系の表示名に切り替え。デッドゾーン 0.22。
  切断で一時停止、フォーカス喪失・タブ非表示で入力をすべて解除して一時停止。タッチ: 左半分の浮きスティック＋右の SHOT（長押し）・POWER・Ⅱ（複数指で同時操作）。
- 3D VR / 3D 通常: 3d/README（実装メモ）と TEST_REPORT.md 参照。左スティック移動・右スティック上下で奥/手前（上で奥、反転設定あり）・右トリガー射撃・右 A パワーアップ・右 B 一時停止・メニューはレーザーとトリガー。

## 6. 画質
- 2D: Canvas 2D にベクターで実解像度を描く（devicePixelRatio まで、最大 4）。4K 画面では 3840×2160 で描く【実測: dpr 2 の 1920×1080 で 3840×2160 のバッファ】。
  自動画質: 2 秒の窓で平均フレーム間隔が 20ms を超えたら 0.85 倍ずつ下げる（下限 0.5）、16.7ms 未満が 6 秒続けば 0.1 ずつ戻す。手動固定（高・中・低）あり。HUD・メニューは DOM の文字（拡大でにじまない）。
- 3D: 別の品質設定（3D 版の実装メモ参照）。

## 7. 音
- 【確定】マスター・BGM・効果音の独立音量とミュート。ユーザー操作で音声を開始。タブ非表示・一時停止で止め、同じ位置から再開。
- 【変更】原作の曲の旋律の再現は**行わない**（著作権のある楽曲のため、公開物への収録は利用許諾なしにはできない）。
  代わりに当時の基板の**音源構成**（AY-3-8910 ×2 ＋ 波形メモリ 2 音、モノラル）をソフトで模擬し、全曲を新規作曲。詳細と根拠は AUDIO_REFERENCE.md。
- 既定はモノラル・残響なしの忠実モード。アレンジ（軽いステレオ・エコー）は任意設定。オプションの弾は効果音を足さない。

## 8. 保存
- localStorage（キー `orbital-wings-gic:v1`）: 設定・ハイスコア（記録キー別）・ステージ解放（2D/3D 別）。保存できない環境では画面に表示してプレイは続ける。
