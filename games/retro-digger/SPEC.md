# SPEC — 確定仕様と採用値

この作品は Claude（Claude Code のクラウドセッション）で制作しました。数値はすべて今回の調整案で、原作の数値ではありません（実体は `shared/config.js`）。

## 依頼からの変更と理由

| 依頼 | 実際 | 理由 |
|---|---|---|
| Unity の新規プロジェクトとして制作 | three.js（WebGL／WebXR）＋JavaScript で制作 | クラウド環境に Unity Editor がなく、Unity 公式 CI イメージの起動は権限判定で止められ、ライセンス有効化には利用者の Unity アカウントが必要だった。利用者に確認し「three.js+WebXR に変更」の回答を得た（2026-11-12） |
| Scenes／ScriptableObject／Prefab などの Unity 構成 | 同じ役割を JS のモジュールに置いた: 状態とルール `shared/rules.js`・`game2d.js`・`game3d.js`、データ `config.js`・`stages.js`、モデル `models3d.js`・`sprites2d.js`、画面遷移は各 `app.js` | エンジン変更に伴う |
| 最後の敵の逃走（任意） | 採用しない | 任意項目。残敵ゼロで正常にクリアする |
| 3D の複数階層（任意） | 採用しない（単層の水平坑道） | 任意項目。床が安定し、迷いにくい |

## ルール（共通）

- 掘ると通路ができ、跡は面の終わりまで残る。新しく掘ったセルだけ 10 点（同じセルで重複しない）
- ポンプ: 発射 → 命中 → 接続 → 送気（0.30 秒間隔。連打でも長押しでも同じ間隔）→ 段階的に膨張 → 規定回数で破裂（追跡型 100・火炎型 150）。
  外す（移動する・射程外・遮られる）と、最終送気から 1.0 秒後に収縮開始、0.5 秒ごとに 1 段階戻る。残り 1 段階で色の点滅と「復帰直前」の音。膨張中は止まっていて、触れても安全
- 岩: 支えあり → 支えを失う（揺れ・砂・警告音・3D は床に赤い輪）→ 予兆時間の後に落下 → 着地して崩れる。落下中に当たった敵を数え、着地時に 1 回だけ 300×n×n 点。通常撃破点は加算しない。主人公も巻き込まれる
- 2D の岩は主人公が真下にいる間は揺れ始めない（掘り上げた瞬間に落ちて逃げ場がない、を防ぐ）。3D は支え（木の枠）をすべて掘ると揺れ始める
- 敵 2 系統（別の AI）:
  - 追跡型「プクモ」: 掘られた道を最短経路で追う。経路がない状態が続く（2D 4 秒・3D 4.5 秒）か、ときどき（11〜16 秒・13〜19 秒ごと、遠いとき）、体が揺れて砂の輪郭になる予兆（0.6 秒以上）の後に土を通り抜ける。通り抜け中・実体化直後 0.4 秒は接触しても安全。実体化は「主人公に通じる通路のセルの中心」に限る（3D は主人公から 1.6m 以内では実体化しない）
  - 火炎型「ボイラン」: 道をたどる（75% は追跡、25% は気まぐれ）。2D は同じ行で射程＋1 セル以内、3D は同じ行／列で見通しがあるとき、向きを決めて溜める（予兆時間）→ 炎（2D 0.9 秒・3D 1.0 秒、射程 3 セル）。炎は土で止まる。通り抜けは経路がない状態が 2 倍長く続いたときだけ
- 処理順（固定）: 移動・掘削 → ポンプ（破裂）→ 岩（押しつぶし）→ 敵・炎 → 主人公への当たり → クリア判定。倒れた敵・膨張中・通り抜け中の敵からは当たらない
- ミス: 敵との接触・炎・落下中の岩で 1 ミス。ミス演出 2.2 秒の間は敵と炎が止まり、落下中の岩は着地まで進む。掘削地形・倒した敵・得点は保持し、開始位置へ復活。生き残りの敵は初期位置へ戻って膨張が解け、1.5 秒待ってから動く。復活後 1.5 秒は保護。ミス中・クリア中・保護中の多重ミスは起きない
- 面の開始直後も、敵は 1.5 秒（＋1 体ごとに 0.25〜0.3 秒）待つ（出現直後の接触死を防ぐ）
- 全滅でクリア（＋1000 点）。時間ボーナスなし。残機は 20,000 点・60,000 点で 1 つずつ増える
- 一時停止中はすべてのゲーム時間（敵・ポンプ・収縮・予兆・岩）が止まる（ロジックは一時停止中に呼ばれない）

## 面の構成（2D・3D とも 6 面）

1 土の坑道（掘削とポンプ）→ 2 土の分岐路（足止めと退避）→ 3 結晶洞窟（岩の支持と落下）→ 4 結晶の交差路（複数の敵の誘導・岩でまとめて）→ 5 火山の地層（火炎・射線・遮蔽）→ 6 火山の迷路（総合）。
2D と 3D は同じ課題を別の配置で作った（座標の使い回しなし）。火炎型は 2D の 3 面から、5・6 面で増える。

## 画面遷移

入口ページ（タイトル・モード選択・制作注記）→ 各モードのタイトル（難易度・通しプレイ／練習・チュートリアル・操作方法・設定）→ 初回チュートリアル（通しプレイの前に 1 回。スキップ可・設定から再表示）→ プレイ → 面クリア → 次の面 → 全クリア。一時停止から再開・設定・やり直し・タイトルへ。残機 0 でゲームオーバー → 新しく挑戦／タイトル。

## 保存（localStorage キー `retro-digger:save`、形式 v2）

設定（音量 4 種・消音・難易度・VR 移動方式・速さ・周辺暗転・スナップ角・左利き・マウス感度・画質・FPS 表示・チュートリアル済み）、
記録（キー = モード［2d／3d／vr-step／vr-smooth］|難易度|run／practice）、解放済みの面。保存できない・壊れている・旧形式（v1）でも既定値で起動する。端末間の同期はない。
