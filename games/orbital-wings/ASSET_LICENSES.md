# ASSET_LICENSES.md — 素材の出所と利用条件

既存素材（旧ソース・画像・モデル・録音）は**存在せず、使っていない**。Google Drive の検索でも本作関連の資料は 0 件だった。
原作のデータ（ROM・画像・音・モデル）の抽出・再配布は行っていない。

| 素材 | 出所 | 作り方 | 利用条件 |
|---|---|---|---|
| 2D の機体・敵・ボス・地形・背景・爆発 | 新規制作 | `2d/render2d.js` のベクター描画（コードで描く。画像ファイルなし） | このリポジトリの作品として利用 |
| 3D のモデル・材質・演出 | 新規制作 | `3d/` のコードで three.js の形状から組み立て（外部モデルなし） | 同上 |
| 曲 14 曲・効果音 24 種 | 新規制作（作曲・音作りとも本作のため） | `shared/audio/songs.js`・`sfx.js` の打ち込みデータを `chip.js` で合成 | 同上。原作の旋律は使っていない（AUDIO_REFERENCE.md） |
| 試聴用の音源書き出し | 上記から生成 | `tools/render-audio.js` | 同上 |
| ロゴ「ORBITAL WINGS」 | 新規 | CSS の文字装飾（端末の標準フォント） | 同上 |
| 日本語フォント | 端末の標準フォント（ヒラギノ / Noto Sans JP / 游ゴシック / メイリオ） | 配布物に含めない | 各 OS のフォント |
| three.js r187 | npm `three@0.187.0` | ルートの node_modules から `dist/vendor/three/` に複製 | MIT License（Copyright © 2010-2025 three.js authors） |
| WebXR エミュレーター IWER | npm（Meta） | **検証のときだけ**一時フォルダに導入。リポジトリ・公開物には含めない | MIT License |

名称について: 「グラディウス」はコナミの作品名。本作は独自タイトル（ORBITAL WINGS・仮称）を使い、トップページとクレジットに
「初代グラディウスに着想を得た非公式作品です。コナミの公式作品ではありません。」と表示している。
ステージの題材（火山・遺跡・石像・生体・細胞・要塞）や装備ゲージという仕組みは参考にしたが、敵・ボス・地形の配置と造形は新規。
