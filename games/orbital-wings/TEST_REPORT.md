## 8. 見つけた不具合（再現条件 → 原因 → 修正 → 再確認）
1. ボスが 1〜7 秒で倒れる（全装備）→ 部位耐久が低く、登場中も当たった → 耐久 ×5・登場中は無敵 → [N] 7〜112 秒
2. 最終ボスが第 1 フェーズから進まない → 部位破壊時の呼び出しがボスの定義ではなく個体を見ていた → 定義を呼ぶよう修正 → [N] 一周クリア
3. 2D の装甲板が中抜け、石像の描画で例外 → 被弾の白光の関数の引数がずれて色の代わりに数値が渡っていた → 引数を修正 → [H] 例外なし
4. 小型編隊機が後ろ向きに描かれる → 余分な 180° 回転 → 削除 → [H]
5. 最初のゲーム開始で例外（メニューを閉じる時の null）→ 修正 → [H]
6. 1 フレーム内に押して離したキーが無視される（メニューが反応しないことがある）→ 次の読み取りまで押した扱いにする → [H] 合格
7. 第 1 面の噴火の岩が密すぎる（自動操縦が毎回同じ場所でミス）→ 発生間隔と数を調整
8. 3D の「立体音響」設定が何もしていなかった → 設定項目を削除（モノラルのまま）

## 9. 未検証・未達（まとめ）
- **Unity での制作**: クラウドで Unity Personal を有効化できず、依頼者の承認で three.js ＋ WebXR に変更（Unity プロジェクト・Unity ビルドは無い）
- **実機**: Quest 3・iPad・50 インチ 4K 画面・実ゲームパッド。すべてエミュレーションまたは画像での確認のみ
- **原音への忠実さ**: 原作の曲・効果音は再現していない（著作権）。試聴・聴き比べも未実施。音源構成の模擬と新規作曲のみ
- **難易度の調整**: 通常プレイ（人）での確認なし。敵を避けない自動操縦では各難易度の妥当性を判断できない
- **複数 Unity プロジェクトの分離試験**: Unity が無いため未実施
- **20 分以上の連続プレイでのメモリ・発熱・音切れ**: 未実施（ロジックの一周は [N] で確認）

## 10. 既知の問題
- 3D のモデルは押し出し・回転体中心の簡素な造形（2D に比べ細部が少ない）
- 開始ファンファーレ（start）は作曲済みだが進行では使っていない
- ヘッドレス（ソフト描画）では自動画質が下限まで下がる（実機の GPU では未確認）
