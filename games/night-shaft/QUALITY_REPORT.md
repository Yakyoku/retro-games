# QUALITY_REPORT — 4K・50 インチ・Quest 3 の画質と性能

## 2D 版（Canvas 2D・すべてベクター描画）

- 画像素材を使わないので、拡大による劣化・アトラス・Mip Map の問題は起きない。人物・建物・文字は描画バッファの解像度でそのまま描く
- 区別している値: CSS の表示サイズ／devicePixelRatio／Canvas の描画バッファ（設定画面とデバッグ表示 `?debug=1` に実値を出す）
- 画質プリセット（設定 → 画質）
  - 自動: 端末の倍率どおり（最大 3 倍・幅 4096px まで）
  - 標準: 最大 2 倍・幅 2560px まで
  - **大画面 4K・高画質**: 描画バッファの幅を 3840px 以上にする（例: 1920×1080 の表示倍率 1 のブラウザでも 3840×2160 で描いて縮小表示）。幅 4096px まで
  - 軽量: 1 倍
- 見える範囲は解像度で変わらない（横はビル全体 26.4m 固定、縦は画面比率に従い最大 7 階）。HUD は CSS で一定の大きさ

| 検査 | 結果 |
|---|---|
| 3840×2160 の描画バッファで画像検査 | 実施。人物の輪郭・文字（階番号・吹き出し）・弾がにじまない（スクリーンショットで確認） |
| 4K での fps | ヘッドレス・ソフトウェア描画で約 10fps / 1 フレーム約 40ms。**GPU 描画の実機の値ではない**ので 60fps 目標の達否は未確認 |
| 1600×900（ヘッドレス） | 約 45fps（ソフトウェア描画）。実ブラウザ（GPU 合成）では軽くなる見込みだが未測定 |
| 50 インチ実画面 | **未確認**（表示端末なし）。「50 インチ実機確認済み」ではない |
| iPhone 13 縦横・iPad Pro 11（Playwright の端末模擬） | タイトル・HUD・タッチ操作盤が重ならず、制作注記が初期表示で見える。縦長タイトルのはみ出しを発見して修正。実機は未確認 |
| レトロ表示（走査線） | 任意。標準の高精細表示は置き換えない |

## VR 版（three.js r187・WebXR）

- 照明は頂点色に焼き込み（MeshBasicMaterial）。動的な点光源・影・ポストエフェクト（ブルーム・被写界深度・モーションブラー・シャープ化）は使わない
- 近くの階（±2）だけ表示。遠い階の状態はゲーム側で保持
- 人物・扉などは Lambert（半球光＋平行光 1 つ）。人物は立っている場所の焼き込み照明の明るさを掛ける
- 文字の板は CanvasTexture（異方性 8・Mip Map あり）

| 画質設定 | framebufferScaleFactor | 固視点レンダリング（foveation） |
|---|---|---|
| 高精細（既定） | 1.25 | 0.25 |
| 標準 | 1.0 | 0.5 |
| 軽量 | 0.8 | 0.5 |

- アンチエイリアス: WebGLRenderer の antialias:true（WebXR のレイヤーで MSAA が有効かは端末次第。実値は未確認）
- リフレッシュ: 既定 72Hz を要求、設定で 90Hz（`supportedFrameRates` に 90 がある時だけ `updateTargetFrameRate`）
- 実際の描画バッファは設定画面に表示（`renderState.baseLayer.framebufferWidth/Height`）。パネル解像度・推奨サイズと区別する

| 検査 | 結果 |
|---|---|
| IWER（Quest 3 模擬）で没入型セッション開始 | 描画バッファ 1280×720（模擬ランタイムの値。Quest 3 実機の値ではない）、対応リフレッシュ 72/80/90/120（模擬値） |
| 画面で遊ぶ 3D（1280×720・ソフトウェア描画） | 描画呼び出し 約 140〜165・三角形 約 2〜3 万。fps はソフトウェア描画で 10〜45（実機の参考にならない） |
| Quest 3 実機の 72Hz/90Hz 安定・フレーム時間・熱・メモリ・10 分連続プレイ | **未確認**（実機なし） |
| 文字のぼけ・遠景のちらつき | **未確認**（実機なし） |

## 再開するとき（実機での確認手順）

1. Quest 3 のブラウザで https://night-shaft-quest3.netlify.app/?debug=1 を開き、「VR で遊ぶ」
2. 一時停止 → 設定に、実際の描画バッファと対応リフレッシュが出る
3. 画面の外に出るデバッグ表示（fps・描画呼び出し）は PC 側のみ。実機の計測は Meta Quest Developer Hub の OVR Metrics Tool 等で行う
4. /probe/ で入力・追跡・再入場を確かめられる
