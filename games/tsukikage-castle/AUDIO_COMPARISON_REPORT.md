# AUDIO_COMPARISON_REPORT — 比較結果と差異

本作は、Claude Codeのクラウドセッションで制作しました。

## 実施しなかったこと（理由）
- **原音との A/B 比較（聴感・波形・スペクトル・ループ周期）は実施していない。** 原作の録音を参照用にも取得しておらず、原作の楽曲は本作で再現しない方針のため、同じフレーズ同士を比べる対象が無い
- **聴感確認は一切していない。** 制作者（Claude）は音を聴けない。Quest 3 の本体スピーカー・ヘッドホンでの確認も未実施
- したがって「原音に忠実」「一致率」などの評価は出さない

## 実施したこと（機械的な確認）
| 確認 | 方法 | 結果 |
|---|---|---|
| 全 14 曲が鳴る・数値の破綻がない | Node でオフライン合成（48kHz）し、NaN・クリップ・ピークを測定（`tests/support.test.js`） | NaN なし・クリップなし。ピーク 0.42〜0.62、RMS −18.7〜−13.9 dBFS（`docs/audio/songs.json`） |
| 小節とループ | 全曲の全小節が 4/4（192 tick）か、ループ曲は全トラックの長さとループ位置がそろうか | 全曲合格。ループは小節単位 |
| ループの継ぎ目 | stage1 のループ点をはさむ 0.5 秒に 50ms 以上の無音が無いか | 合格（継ぎ目で途切れない） |
| 効果音 | 全 45 種を単独で合成し NaN が無いか、対応表の参照先がすべて存在するか | 合格 |
| 音色の傾向 | 各曲の最初の 12 秒のスペクトログラム（0〜8kHz）とスペクトル重心を作成（`docs/audio/spectrograms.jpg`） | 重心 4.2〜5.4kHz（明るく硬い音）。矩形波を素朴に生成しているため、高い音で折り返し（エイリアシング）の線が見える。当時の素朴な音源らしさとして残したが、耳で確かめていない |
| ブラウザでの再生 | 公開サイトを headless Chromium で開き、AudioWorklet の起動・曲の切り替え・出力のピークを確認 | 2D・3D とも AudioWorklet で起動、ステージ曲が再生（ピーク約 0.29） |
| 同期・二重再生 | 出来事（命中・撃破・鎧破壊・死亡）と同じ tick で効果音を出す設計。同じ曲の再要求は無視、同じ効果音の連続は 40〜300ms で間引き | コードとテストで確認。実際の聴感上の同期は未確認 |

## 差異・残る課題
- 原作との差異は評価していない（比較対象なし）
- 矩形波の折り返しノイズ、FM の高音の硬さ、音量バランス（矩形波の旋律が FM の和音より前に出る設計）は、実際に聴いて調整する必要がある
- 曲ごとの音量差は RMS で約 4.8dB。聴感での揃え込みは未実施
