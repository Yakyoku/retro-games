# ASSUMPTIONS — 原作確認事項・今回のアレンジ・最終調整数値

本作は、Claude Codeのクラウドセッションで制作しました。

## 原作について確認したこと／していないこと
- 参照作品は 1985 年アーケード版『魔界村』。**このセッションでは原作の映像・音源・基板資料を実際に参照・解析していない。**
  ゲームの数値・ステージ構成・敵の挙動は、依頼書の「推奨する初期設定」を出発点にした本作独自の調整値であり、原作の解析値ではない
- 「鎧 → 被弾で鎧が壊れる → 次で倒れる」「投げ武器の持ち替え」「踏み切りで決まるジャンプ」「墓から湧く亡者」など、
  ジャンルとして知られた仕組みは取り入れたが、原作のキャラクター（主人公・姫・魔王・赤い悪魔など）、面の地形、敵の造形、曲は再現していない
- 主人公は鎧を失うと「赤い上着と濃い色のズボン」の姿になる（原作の有名な外見とは変えた）
- 音源チップの種類は推測で断定していない（AUDIO_REFERENCE.md）

## 今回のアレンジ（依頼書にない、または解釈したもの）
| 項目 | 内容 | 理由 |
|---|---|---|
| 鎧の回復 | 各ステージ 1 つ「鎧」アイテム（鎧が壊れていれば着直す・200 点） | 鎧が壊れた後の緊張感を保ちつつ、6 ステージを通して遊べるように |
| 武器の入手 | 決まった場所の光る武器と、特定の敵（骨・術者など）が落とす武器。復活は槍 | 拾いたくない武器は跳び越えられる。湧く敵からは落ちない（稼ぎ防止） |
| ボスの隙 | 攻撃後の硬直中は被ダメージ 1.5 倍、HUD に「隙あり」 | 「攻撃後の隙を狙う」を手触りで分かるように |
| ボスの体力表示 | 画面下に名前と体力の帯 | 覚えて攻略する手がかりとして（原作にあるかは未確認） |
| 時間警告 | 残り 30 秒で時間表示が赤く点滅（音は鳴らさない） | 原作で鳴らない音を足さない方針 |
| 投げの硬直 | 地上で投げた瞬間 0.14 秒だけ足が止まる | アーケードらしい重さ。空中では止まらない |
| 空中の後ろ投げ | 空中で反対方向を押して攻撃すると、速度はそのまま向きだけ変えて投げる | 空中攻撃を有効にしつつ空中の方向転換はさせない |
| しゃがみ移動 | しない（しゃがむと止まる） | 依頼書の「頭上が低い場所で無理に立ち上がらない」は安全装置として実装 |
| 2 周目 | エンディング後に選べる。敵の待ち時間と弾が 25% 強く、ボス体力 1.25 倍 | 1 周目でまず完結させる |
| 中間地点 | 易しい難度のみ追加の中間地点（各ステージ 1〜2 か所） | 依頼書どおり |
| ボスの間の門 | ボス戦が始まると左が閉じる（塔は床の穴をふさぐ） | 戦闘前の中間地点からやり直せる |
| VR の視点 | 横長のステージは 16u ごと、塔は 9u ごとの区画。端から 2.5u で 0.2 秒暗転して切り替え | 依頼書の初期設定案どおり |
