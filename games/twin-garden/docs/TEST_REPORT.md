## エミュレーター（IWER・Quest 3 プロファイル）— 20 件すべて合格
VR 開始（isPresenting）・左右眼 2 視点・90Hz・コントローラーを handedness で判別・VR 中のメニューを A/X とスティックで操作・左スティックで赤だけ・頭を横に向けてもスティックの奥は庭の奥・左右の向き・B で一時停止しゲームが止まる・レーザー＋トリガーでメニュー項目を選ぶ・visible-blurred で一時停止・VR 終了 → 再入場 → 再開・直接操作（トリガー中だけレーザーの先へ、1 tick 最大 0.0833 単位＝通常の速さ）・没入スケールへの切り替え。
見つけて直したもの: 目の高さ 1.6m では庭が視野の外だった（入った時の目の高さから台の高さを決めるように変更）、没入スケールで芝が床と同じ高さでちらつく、暗転の切り替えが止まることがある。
