# ASSET_LICENSES

この作品は Claude（Claude Code のクラウドセッション）で制作しました。

| 種類 | 出典 | 利用条件 |
|---|---|---|
| 画像（2D の絵・芝・枠） | すべて Canvas 2D のコードで描画（`experiments/01-2d/render2d.js`） | この作品のために作成 |
| 3D モデル | すべてコードで生成（回転体・押し出し・球の変形。`experiments/02-vr/models.js`） | この作品のために作成 |
| 宝の 6 マーク | 計算で作った点列（`shared/ui/marks.js`） | この作品のために作成 |
| 曲・効果音 | 自作の MML（`shared/audio/songs.js`）と Web Audio の合成（`shared/audio/audio.js`） | この作品のために作成。原作の曲・効果音・録音は使っていない |
| フォント | 端末に入っている日本語フォントを使う（同梱しない） | 各端末のフォントの条件による |
| three.js r187 | npm `three` | MIT License |
| error-overlay.js | 同じリポジトリの VOIDBLOOM（bio-hshooter）から複製 | 同じ制作者 |
| 試験用（同梱しない） | Playwright、IWER（Meta, MIT） | 作業用フォルダでのみ使用 |
