# CLAUDE.md — NIGHT SHAFT（games/night-shaft）の記録

このゲームは、Claude Codeのクラウドセッションで制作しました。

- 目的: エレベーターで階を移動しながら書類を集めるスパイアクションを、2D ブラウザ版と Meta Quest 3 WebXR 版で作る
- 対象: 制作者本人（大人）。PROCESS.md §9 は適用しない
- 公開: night-shaft-2d（VARIANT=2d）・night-shaft-quest3（VARIANT=vr）。netlify-sites.json
- デバッグ: `?debug=1`（fps・描画バッファ・状態）。2D は I で無敵、C で書類を回収済みに（デバッグ用・表示あり）

## 判断ログ

- 2026-11-12 Unity は使わない。環境に Editor・ライセンス資格情報・GPU が無く、Unity ID の認証には利用者の秘密情報が要る。リポジトリの既存構成（three.js・ルートの build-game.js）で作り、Unity 製とは書かない（依頼の条件変更に当たるので最終報告で明示）
- 2026-11-12 既存作品のキャラクター・楽曲・効果音の再現はしない。遊びの仕組みだけを参考にしたオリジナル（主人公・敵・曲・効果音・タイトル NIGHT SHAFT）。注記も「再制作」ではなく「着想を得たオリジナル」と書く
- 2026-11-12 ステージは手作業ではなく、棟ごとの方針＋固定 seed で生成し、到達性を自動操縦のテストで保証する（30 階 × 3 の手作業より確実に検証できる）
- 2026-11-12 昇降路はかごが居なければ穴。かごの床と屋根に立てる。屋根の上で上昇すると挟まれる（敵は 300 点）。呼び出しボタンで詰まりを防ぐ
- 2026-11-12 VR では穴の縁にレーザー柵（プレイヤーは穴・屋根に入れない）。落下・挟まれは VR で起こさない。敵は 2D と同じく屋根を渡る
- 2026-11-12 2D はすべてベクター描画（画像素材なし）で、4K でも劣化しない。VR は頂点色への照明の焼き込み
- 2026-11-12 音は自作シンセで事前レンダリング（ループ位置がサンプル単位で正確）。WAV マスターは同じコードから書き出す
- 2026-11-12 ローカルにサーバーを立てない（利用者の希望）。Playwright の要求横取りと Netlify の公開 URL で確認
- 2026-11-12 WebXR の模擬に IWER を使った（npm、scratchpad のみ）。不具合 4 件を発見・修正（TEST_REPORT §3）
- 2026-11-12 ルートの package.json には依存を足していない
