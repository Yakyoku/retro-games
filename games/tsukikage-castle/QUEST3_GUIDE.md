# QUEST3_GUIDE — Meta Quest 3 で遊ぶ

本作は、Claude Codeのクラウドセッションで制作しました。**Quest 3 実機での確認はまだ行っていません**（確認は WebXR エミュレーター IWER の Quest 3 プロファイルまで）。

## 開き方
1. Quest 3 のブラウザで https://tsukikage-castle-vr-yk.netlify.app/ を開く（専用アプリのインストールや PC からの映像配信は不要）
2. 「3D / VR 版で遊ぶ」→ タイトルの「VR で遊ぶ（Meta Quest 3）」を選ぶ（このブラウザが immersive-vr に対応している場合だけ表示）
3. 目の前 1.6m に、幅約 2m の「箱庭」が現れる。座っても立っても遊べる（設定 → VR の表示）

## 操作（右利き・既定）
| 操作 | ボタン |
|---|---|
| 移動・しゃがみ・はしご | 左スティック（デッドゾーン 0.15） |
| ジャンプ | 右 A |
| 攻撃（長押しで連射） | 右トリガー |
| ポーズ | 右 B |
| メニュー | レーザーを向けてトリガー、または左スティック上下＋右 A（決定）・右 B（戻る） |
| 正面を合わせ直す | ポーズ → 設定 → VR の表示 → 正面を合わせ直す |

- 左利き設定（設定 → 左利き）で、右スティック移動・左 X ジャンプ・左トリガー攻撃・左 Y ポーズに入れ替わる
- 左右はコントローラーの「利き手（handedness）」で判定しており、配列の番号では決めていない。システム用のボタン（Meta ボタン等）は使わない
- 頭をどちらへ向けても、スティックの左右は盤面の左右のまま（エミュレーターで頭を 90° 回して確認済み）

## 見え方
- 区画ごとに観察位置が固定され、キャラクターが区画の端に近づくと 0.2 秒暗転して次の区画へ移る。暗転中はゲーム（時間・ダメージ）が止まる
- ジャンプや被弾でカメラは揺れない。頭の動き（追跡）はそのまま反映し、上書きしない
- 箱庭の外側は切り落とされ、奥の空と遠景は窓の中だけに見える（頭を動かすと地形・柱・遠景の視差が出る）
- HUD とメニューは盤面のすぐ手前の板に表示（地形に隠れない）

## 画質（設定 → VR の表示 → VR の画質。次に VR を始めたときに反映）
| 設定 | 描画倍率 | 固定フォビエーション | 要求フレームレート | 影 |
|---|---|---|---|---|
| 高画質優先 | 1.3 | 0.3 | 90Hz（対応時） | あり |
| 標準（既定） | 1.1 | 0.5 | 90Hz（対応時） | あり |
| 安定性優先 | 0.9 | 0.8 | 72Hz | なし |

- フレームレートは `XRSession.updateTargetFrameRate`、対応一覧に無ければ 72Hz。視線追跡は使っていない
- 負荷対策: 地形はインスタンス描画、動かない飾りは材質ごとに結合、点光源は 3 つだけを近くの光へ割り当て、粒子は 1 回の描画、HUD の板の更新は 12〜20Hz
- **72fps / 90fps を実機で達成できるかは未測定**（クラウドの描画性能は Quest の性能の目安にならない）

## 音
- 通常版と同じ音（立体音響は加えていない）。VR の開始・終了で音声を再開する
- Quest の本体スピーカー・ヘッドホンでの聴感確認は未実施

## 実機で確認してほしいこと（チェックリスト）
1. 「VR で遊ぶ」で VR に入れるか、箱庭が正面の見やすい高さにあるか（座位・立位）
2. 左右の目で絵がずれたり、片目だけ消える効果がないか（粒子・炎・光線）
3. HUD とメニューの文字が読めるか、レーザーとトリガーで選べるか
4. 区画の切り替えの暗転で酔わないか
5. 長時間（30 分程度）遊んでフレームの落ち・発熱・音の途切れがないか
6. VR を終えたあと、ポーズ画面に戻り、操作と音が正常か
