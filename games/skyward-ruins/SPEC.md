# SPEC.md — 仕様・採用値・仮定・変更理由

## 作品の位置づけ（重要な変更）
依頼は特定の既存アーケード作品の再制作でしたが、既存作品の名称・キャラクター・造形・楽曲・面構成・見た目の再現は制作できないため、
**遊びの仕組み（対空と対地の撃ち分け、地上照準、隠し対象、大型要塞、16 エリア、周回）は依頼どおり実装し、
自機・敵・要塞・地上絵・曲・効果音はすべて独自デザインで新規制作**しました。リポジトリ README の方針（オリジナル作品）とも一致します。
仮称「Skyward Ruins（空の遺跡）」。ゲーム内に既存作品名は出しません。

| 依頼の呼び方 | この作品 |
|---|---|
| ソルバルウ相当の自機 | 自機「スカイワード」（銀白の細身デルタ翼・背骨状の胴・双垂直尾翼・青い風防） |
| ザッパー（対空） | 対空射撃（前方の光弾） |
| ブラスター（対地） | 対地爆撃（照準の地点へ落ちる爆弾） |
| バキュラ相当 | シャード（破壊不能の黒曜石の板。回転・弾を止める） |
| ソル相当 | オベリスク（地中の石柱。照準が金色に点滅 → 爆撃で出現 100 → 追加爆撃 2 回で破壊 500） |
| スペシャルフラッグ相当 | バナー（隠された旗。爆撃で出現 → 接近で 1 機追加） |
| アンドア・ジェネシス相当 | 大型要塞（六角の浮遊基壇＋外周の砲座＋開閉する虹彩コア） |

## 構成
- **ゲーム論理** `unity/SkywardRuins/Assets/SkywardRuins/Core/`（UnityEngine 非依存。asmdef `noEngineReferences`）
  - `Sim.cs` 固定 60Hz の決定的な進行。2D と 3D はこれを読むだけ（判定・ルールを共有）
  - `Stage.cs` 16 エリアの地形と出現データ（エリアごとのシード）。Unity ではエディタ処理が `AreaAsset`（ScriptableObject）へ保存
  - `TerrainPainter.cs` 地表のドット絵（2D の地面・3D の地形テクスチャ共通）
  - `Tuning.cs` 調整値（Unity では `GameDatabase.tuning` としてインスペクタで調整）
- **Unity 層** `Runtime/`：Services（永続：音・入力・XR・カメラリグ・UI）、View2D、View3D、GameRunner、TitleController、UI（メニュー・HUD・設定）
- **エディタ処理** `Editor/ProjectBuilder.cs`：プレイヤー設定・取り込み設定・マテリアル・メッシュ・DB・URP・XR・プレハブ・4 シーンを生成し、検証する（再実行しても同じ結果）
- **シーン**：Boot（サービス初期化）→ Title（注記・モード・難易度・設定・練習エリア、背景は 3D デモ）→ Game2D / Game3D。一時停止と結果は共通メニュー

## 座標・時間
- 論理画面 224×288（指示書の推奨初期値。原作解像度の断定ではない）。原点左下、+y が進行方向
- 空中層は画面座標、地上層は地表座標 worldY（画面 y = worldY − scroll）
- 固定ステップ 60Hz。描画は補間（72/90Hz でも速度は変わらない）。1 フレームの追いつきは最大 5 ステップ、超えた分は捨てる
- 3D は論理 (x, y) → 盤面ルート内 (x−112, 高さ, y)。空中層の高さ 18。盤面ルートの拡大率で通常 3D（0.1）と VR（0.0105×設定、卓上の盤面）を切り替え、XR のメートルと分離

## 進行
- 規定距離（3240）で次エリア。雑魚の全滅は不要。地表は連続（継ぎ目 10 行は共通規則で草原寄り、地上物はエリアをまたいで座標を引き継ぐ）
- 16 エリア通過で「n 周達成」→ エリア 1 へ。敵弾 +10%/周
- 死亡：戦闘停止 → 残機があれば現エリアの開始地点から復帰（同じシードで同じ攻撃）。得点は保持
- 固定対象（地上物・隠し対象・要塞）は周回・エリア・ID で報酬を管理。**破壊・取得済みの固定対象は復帰後も再出現しない**（重複加点なし）
- 残機 0 で結果（得点・到達エリア・ハイスコア・リトライ・タイトル）。練習は「同じエリアに再挑戦」

## 敵（空中は画面座標、地上は地表座標）
| 種別 | 動き | 攻撃 | 耐久・得点 |
|---|---|---|---|
| ダート | 横一列の編隊で直進、少し自機へ寄る | なし | 1・100 |
| アーク | 降下して旋回し、上へ抜ける | 旋回中に 35% で 1 発 | 1・100 |
| シーカー | 1.7 秒だけ自機へ曲がって接近し、そのまま抜ける | 体当たり | 1・100 |
| クロッサー | 画面の横から横切る | 中央付近で予兆 → 1 発 | 1・100 |
| スナイパー | 降下して停止 | 予兆 → 3 方向 → 上へ離脱 | 1・100 |
| ヘビー | 降下・左右に揺れて滞空 5 秒 → 下へ | 予兆 → 1.3 秒ごとに 1 発 | 5・200 |
| シャード | 板の列が降りてくる | 体当たりのみ（弾を止める） | 破壊不能 |
| 砲台 | 固定 | 予兆 → 2.3 秒ごと | 1・200 |
| 移動砲台 | 道路上を往復 | 予兆 → 3.1 秒ごと | 1・300 |
| 掩体 | 固定 | 予兆 → 2 方向 | 2・500 |
| レーダー | 固定 | なし | 1・300 |
| 大型要塞 | 接近（警告 3 秒前）→ 滞空 16 秒（地表のスクロールを 25% に落とす）→ 離脱 | 砲座：予兆 → 1.9 秒ごと／コア：開いている間に 5 方向 | 砲座 1・200、コア 3,000 |

**要塞のコアに有効な武器と条件（独自設定）**：コアは地上層で、**対地爆撃だけが有効**。虹彩が 3 秒周期で開閉し、開いている 1.6 秒の間の着弾だけが有効（閉じていると「カン」と弾かれる）。
コア撃破で全砲座も破壊・敵弾消去・3,000 点。撃破しなくても離脱し、エリアは続く（進行不能にならない）。

- 画面外・画面端からは撃たない。発射前に必ず予兆の点滅がある（不可避な攻撃の防止）
- ランダム性はシード管理（ステージ生成はエリアごとのシード、戦闘中の乱数はエリア開始ごとに再シード）

## 画面・入力
- 2D：224×288 のレンダーテクスチャを点補間で拡大。safe-area 内に縦横比を保って最大表示、余白で画面形状を吸収。縦持ちタッチでは下にボタン帯
- 3D：斜め見下ろし（初期）／コックピット（水平固定・ロールなし・振動なし）。縦長画面では視野を広げて横幅を必ず収める
- VR：卓上の盤面（目の高さより約 0.6m 下、手前 0.42m から奥へ約 3m）。スクロールで頭やカメラを動かさない。コックピットは自機の操作でのみ視点が動き、周辺減光を連動。照準は地上の着弾面に置いた立体の輪（両眼で同じ地点）
- メニュー・HUD は VR では立体空間のキャンバス（正面 1.7m）。コントローラーのレイ＋トリガーで操作
- 入力：キーボード（矢印/WASD・Z 対空・X 対地・Esc。再割当可）、ゲームパッド（South 対空・West 対地・Start。入れ替え可、トリガーも可）、タッチ（左で浮動スティック、右下に大きな対空・対地ボタン、複数指）、Quest（左スティック移動・右トリガー対空・左トリガー対地。利き手で左右入れ替え、B で戻る）
- 切断・フォーカス喪失・XR 中断・VR 終了 → 入力解除して一時停止。再開時はいったん全入力を離すまで受け付けない

## 保存
`PlayerPrefs`（Web では IndexedDB）に設定と、`2D|3D / 難易度 / 支援設定` ごとのハイスコア。練習は記録しない。保存失敗時はメッセージを出してプレイは継続。

## 音
`AUDIO_REVIEW.md` を参照。イベント → 音は `Data/audio_events.json`（データ管理）。AudioMixer・DSP は Web で使えないため各 AudioSource の音量で全体・BGM・効果音を掛け合わせる。

## 仮定
- Web は WebGL2 のみ（WebGPU は使わない）。マルチスレッド無効（クロスオリジン分離が不要）
- Brotli 圧縮。Netlify の `_headers` で `Content-Encoding: br` と MIME を付ける
- WebXR は `local-floor` 参照空間（座位でも盤面は卓上の高さ）
