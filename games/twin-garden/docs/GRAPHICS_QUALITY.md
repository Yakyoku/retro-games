# GRAPHICS_QUALITY

この作品は Claude（Claude Code のクラウドセッション）で制作しました。

## 2D（PC・タブレット）
- すべてベクター描画で、描画バッファ＝CSS の表示サイズ × devicePixelRatio（引き伸ばしなし）。画面の大きさ・倍率・モニターの移動に追従
- 芝の背景だけは面ごとに 1 回、実解像度で焼いて使う（拡大した画像ではない）
- HUD・メニューは DOM の文字（4K でもにじまない）
- 「大画面・最高画質」（既定）は内部解像度を下げない。「自動」は 50fps 未満が続くと 0.1 ずつ最大 0.5 倍まで下げ、58fps を超えると戻す（`?debug=1` で実際の描画バッファと倍率を表示）

### 確認した結果（headless Chromium・SwiftShader）
| 条件 | 結果 |
|---|---|
| 3840×2160・倍率 100% | 描画バッファ 2614×1996 = 表示サイズと同じ（盤面は 4:3 なので横は余白） |
| 1920×1080・倍率 200% | 描画バッファ 2603 ＝ CSS 1301.6 の 2 倍 |
| 4K の等倍の見た目 | スクリーンショットで線・文字・輪郭がにじまないことを目視（作業用の画像） |
| **50 インチの実物** | **未確認**（実物の画面がない） |
| 実 GPU での 4K・60fps・フレーム時間 | **未計測**（制作環境はソフトウェア描画） |

## 3D／VR
- three.js r187・ACES のトーンマッピング・影（PCF・PC 2048、Quest 高画質 1024、最高画質 2048）・アンチエイリアス（WebGL の MSAA）
- モデルは回転体・押し出しで作った立体（板の代用品なし）。宝のマークも厚みと面取りのある押し出し。小物には柔らかい接地影の円も重ねる
- ラインは円柱のインスタンス描画（0.6 単位ごとの小片で赤→白→青）
- 芝のテクスチャ 2048×1536（ミップマップ・異方性フィルタリング最大）
- VR の画質: 「Quest 3・高画質」（既定）＝フレームバッファ倍率 1.0・固定フォービエイション 0.5 ／「Quest 3・最高画質」＝倍率 1.35・フォービエイション 0.15。どちらもゲーム内容・判定は同じ
- 更新レート: セッションが 90Hz に対応していれば 90Hz を、なければ 72Hz を要求する
- `?debug=1`: VR 中の HUD に平均 fps・フレーム間隔の 95/99 パーセンタイル・実際のフレームバッファの大きさ・更新レート・画質を表示（実機での記録用）

### 確認した結果
| 条件 | 結果 |
|---|---|
| PC の通常 3D（headless・SwiftShader） | 描画できる。1 フレーム 約 420 描画呼び出し・約 11.4 万三角形 |
| WebXR エミュレーター（IWER・Quest 3 プロファイル） | 左右眼 2 視点、90Hz、フレームバッファ 1280×800（エミュレーターの値。実機の値ではない） |
| **Quest 3 実機の画質・性能・20 分連続・発熱** | **未実施**（実機がない）。超高画質の実機受入確認は未実施 |
