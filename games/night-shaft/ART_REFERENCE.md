# ART_REFERENCE — キャラクターと美術

## 方針（依頼からの変更）

依頼は「1983 年アーケード版の主人公・敵・動作を基準に、当時のタイトーの表現を踏襲」だったが、既存作品のキャラクター造形の再現は行っていない。
したがって **原作の公式画像・映像との比較は行っておらず、「原作らしさ」の検証結果も無い**。参照したのは「1980 年代前半のアーケードの人物表現の一般的な性質」だけである:

- 少ない色数で、人物どうしを配色の塊で見分けられる（主人公＝紺と橙、敵＝えんじと灰）
- 横から見て輪郭がはっきりした、頭・胴・脚の比率が分かりやすい体形
- 歩く・構える・しゃがむ・跳ぶ・倒れるが、静止画でも区別できる大きな姿勢差

## 主人公（エージェント「KITE」と制作上呼んだ）

- 紺のロングコート（腿の中ほどまで）・濃紺のズボン・黒の靴・黒い手袋
- 橙のマフラー（2D では揺れる 5 節、3D では首元の輪＋後ろへなびく 3 節）。遠目でも主人公と分かる印
- 黒の短髪（横分け・前髪）・肌色の顔（目・眉・鼻・耳）
- 銀色の拳銃を片手で水平に構える
- 頭身はおよそ 7（身長 1.75m、頭の半径 0.125m）

## 敵（警備員）

| 型 | 見た目 | 行動 |
|---|---|---|
| 0 | えんじの制服・灰色のヘルメット・白いバイザー | 立って撃つ |
| 1 | 型 0 ＋ 黄色の腕章 | 低い弾も撃つ。撃たれそうになるとしゃがむ |
| 2 | 暗いえんじ・濃灰のヘルメット・灰色のベスト・琥珀色のバイザー | 遮蔽物の陰で待ち、立って撃つ |

- 構えるとバイザーが橙→赤に光る（撃ってくる合図。色だけでなく、銃を水平に構える姿勢も変わる）。低い弾の構えはしゃがみ姿勢＋銃口の三角

## 2D と 3D で同じ人物にするための工夫

- 姿勢は共通の関数（`shared/art/pose.js`）。関節位置を 2D は線と面で、3D はカプセル・回転体・球で描く
- 脚は 2 関節 IK で足先を地面に置く。歩幅は移動距離から決まる（位相 π = 0.8m）ので足が滑らない。床への埋まりも起きない
- 銃は手前の手の前腕の向きに固定（手から離れない）
- 配色は `shared/art/palette.js` を両方で使う

## 資料で確認した特徴と、補った部分

- 確認した資料: なし（上記のとおり原作資料は使っていない）
- すべて創作: 背面（髪・ヘルメットの後ろ）、側面、コートの立体形状、マフラー、顔の部品

## 背景

- 夜の都市（星・月・窓明かりのビル群）、ビルの内装は棟ごとに配色を変えた（オフィス = 暖色の木、研究 = 青緑、警備 = 灰緑と赤）
- 赤いドアは色＋書類マーク＋上の三角の旗で区別、回収後は青緑＋チェックマーク（形でも区別）

## 改訂 v2（2026-11-12）: キャラクターの動きとデザインの 30 項目

利用者の指摘（動き・デザインが貧弱）を受けて、全姿勢を並べたシート（`experiments/01-2d/sheet.html`・`experiments/02-vr/sheet.html`、公開ページからはリンクしない確認用）で診断した。
見つかった主な問題: 敵のヘルメットが上下逆に描かれていた（頭頂が肌色に見える）／立ち・歩きで常に膝が深く曲がる／接地と蹴り出しの区別が無い／死亡時に胴と脚が分離して床に沈む／胴が平板・手足が同じ太さの棒／状態の切り替えと振り向きが瞬間的。

動き（shared/art/pose.js の computePose と Animator。2D・VR 共通）
1. 脚の比率を再設計（股下 0.975m・すね 0.45m）し、立ち姿で膝が自然に伸びる
2. 歩き↔走りを速度で連続ブレンド（巡回は歩き、プレイヤーは走り）。位相は実際の移動距離から進め、足が滑らない
3. 接地→沈み込み→通過→伸び上がりの骨盤の上下
4. かかと接地・つま先の蹴り出しで足首が回る
5. 走りの滞空期と、後ろ脚の蹴り上げ
6. 肩と腰の逆ひねり
7. 腕振りの位相遅れと肘の曲げ（走りは深く）
8. 移動中は銃をローレディ（銃口は前下）で保持
9. 両手保持の射撃姿勢（腕の 2 関節 IK。奥の手が銃を支える）
10. 射撃の反動（銃口の跳ね上がり・腕の引き・頭）
11. しゃがみを片膝立ちに。銃の高さを当たり判定（0.72m）と一致
12. 敵の低い弾は腰だめの低い構え（弾の高さ 0.42m と一致）
13. 構えの予兆: 下げた銃を水平まで上げていく（敵の構え時間に連動）
14. ジャンプの上昇（伸び）・頂点（抱え込み）・下降（脚を伸ばして着地準備）
15. 溜めてから伸ばす飛び蹴り（上体を反らし、腕でバランス）
16. 着地の沈み込み（落下速度で深さが変わる）
17. 被弾ののけぞり
18. 死亡: のけぞり→膝が崩れて後ろへ倒れる→床に横たわって小さく弾む（床に沈まない）
19. 状態の切り替えを 0.12 秒でクロスフェード
20. 振り向き（2D は横幅の反転、VR は体が実際に回る）
21. 加減速で前傾・のけぞる（ばね）
22. 待機中の呼吸と重心移動、頭のゆらぎ
23. まばたき（主人公。2D・VR とも）
24. コートの裾が速度と縦の動きで揺れる（2D は多角形、VR は裾の回転）
25. エスカレーターでは段差に足を置き、ドアでは取っ手へ手を伸ばす

デザイン（experiments/01-2d/person2d.js・experiments/02-vr/chars3d.js）
26. 敵のヘルメットを正しい向きに（頭の上にかぶる）。つば・耳当て・回り込むバイザー・あご紐
27. 太さの変わる手足と関節、肩と胸の形のある胴、かかと・靴底のある靴、親指つきの手袋、スライド・フレーム・用心金のある拳銃
28. 主人公: 襟とラペル、真鍮のボタンとバックル、二股のコート裾、髪のハイライトと前髪、目・眉・鼻・口、太い布のマフラー
29. 2D: 暗所でも読める輪郭線（2 パス）・2 段の陰影（胴は背→前のグラデーション、手足は前側の明るい帯）・背中側の青いリムライト。VR: 3 段のトゥーン陰影（輪郭線は Quest の描画負荷を倍にするため使わない）
30. 敵 3 型の差別化: 体格（型 0: 1.05 倍、型 2: 1.12 倍）・肩章・ブーツ・胸ポケット・無線機・ポーチ、型 1 は黄色の腕章、型 2 は防弾ベストと胸の装甲板・琥珀色のバイザー

確認: 2D シート（1 姿勢ずつ）・実際のプレイ画面（走りながらの射撃・被弾・死亡）・VR シート（正面・側面・背面）・IWER の XR 模擬試験（全項目合格）。
VR の描画呼び出しは人物の部品が増えたため約 160→265（画面で遊ぶ 3D・敵が近くに数体の場面）。Quest 3 実機での負荷は未計測。

## 改訂 v3（2026-11-13）: 現代のアーケード水準へ — キャラクター 30・背景 30

### キャラクター（30）
1. カメラを寄せ（見える幅 26.4m → 16.5m、横もプレイヤーを追い、向いている方を 2.4m 先まで見せる）、人物が約 1.6 倍の大きさで見える。設定で「全体」に戻せる
2. 人物を 1 人ずつ作業用キャンバスに描き、形の内側だけに照明を重ねる（はみ出さない陰影）
3. いちばん近い点灯中の照明の側が暖色に明るくなる（距離で強さが変わる）
4. 頭の上から当たる光（上半身が明るい）
5. 暗がりでは背中側に青い月明かりの縁取り
6. 足元の接地影（足が浮くと薄く小さく、倒れると横長）
7. 撃たれた瞬間の白い発光（敵・主人公）
8. 主人公の銃口の閃光が自分の体を照らす
9. 無敵中は脈打つ青い光の縁取り（点滅で消えない）
10. 敵は扉の光を背にした影から現れる
11. 敵が気づいた瞬間に頭上へ「!」が飛び出す
12. 構えると、バイザーのにじむ光と、撃つ高さを示す赤い照準線（予兆が読みやすい）
13. 星形の銃口の閃光とにじみ（敵は橙）
14. 薬莢が飛び、床で跳ねて転がる
15. 走ると足元に土ぼこり、着地・撃破・照明の落下でもほこり
16. 撃破時の衝撃の輪と光る火花（加算合成の尾）
17. 主人公のワイシャツとネクタイ（ラペルの間）
18. 敵の胸章（金色のひし形）
19. 型ごとのヘルメットの線（白・黄・橙）
20. 靴ひものハイライト
21. マフラーを布の帯として描く（輪郭・影・明るい面の 3 層）
22. 書類を取ると金色の輪が広がる
23. 照明の落下・撃破で画面を軽く揺らす（回転なし）
24. VR: 足元の接地影
25. VR: 撃たれた瞬間に全身が白く発光
26. VR: 構えるとバイザーの光が強くなる（加算スプライト）
27. VR: 背後からの青い縁取り光（夜の雰囲気と輪郭の読みやすさ）
28. VR: 倒れると影も横長に
29. 軽量の画質では作業用キャンバスの合成を省く（古い端末向け）
30. 構えの予兆の光は撃つ高さ（高い弾・低い弾）で位置が変わる
