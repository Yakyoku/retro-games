# AEGIS RELAY 2D 版 — 見た目と滑らかさの作り直し（実装記録）

この作品は Claude（Claude Code のクラウドセッション）で制作しました。

docs/UPGRADE.md の A（C01–C30）・B（B01–B30）と、D のうち 2D の描画に属する項目（M01–M05, M07–M09, M12–M16, M25–M30）の実装記録。
ルール・判定（shared/）には手を入れていない。変えたのは play2d/ だけ。画像ファイル・外部 URL は使わず、絵はすべて起動時・エリア開始時にコードで作る。

## 構成（play2d/）

| ファイル | 役割 |
|---|---|
| render2d.js | 全体の進行（描く順・画質・自動画質・光のにじみ・周辺減光・走査線・デバッグ表示） |
| bg.js | 宇宙: 星雲・星 3 層・光条・天体・遠景の岩・雲・流れ星・ワープの筋・盤面の外の飾り |
| terrain.js | 浮遊大陸: 高さマップの陰影・崖を「帯」に焼く。先読み・破棄・焦げ跡 |
| materials.js | 8 テーマの地表の素材（高さ・色・光沢・発光） |
| terrain-detail.js | 遺跡・導線・土台・紋様・岩・配管・草・象嵌・崖下の結晶（焼くときだけ） |
| actors.js | 地上の標的・空の敵・支援機・自機・弾の描画と、できごと → 演出の対応 |
| fx.js | 粒（使い回し）・爆発・衝撃波・光・数字・環境の粒・落ちる粒・画面の揺れ |
| atlas.js | 焼いたスプライト・光の玉・火球/煙のコマ・文字の置き場 |
| sprites/kit.js, player.js, enemies.js, ground.js | 絵の定義（装甲板・パネルライン・光沢・縁光の道具と、各機体） |
| themes2d.js, util.js | テーマ別の設定・共通の光源、ノイズ・色・時間分割の仕事 |

描く順: 宇宙 → 大陸（帯）→ 発光の層 → 地上の標的 → 爆発の照り返し → 薄い雲 → 影 → 空の敵・支援機・自機弾・自機 → 煙・火・火花・破片 → 環境の粒 → **光のにじみ** → 周辺減光 → **敵弾**（にじみより後・いちばん上）→ 得点の文字 → 閃光・走査線。

## 計測（このコンテナ。GPU がなくソフトウェア描画なので、前後の比較用）

`renderer.frame()` 1 回＋描画の強制実行（120 フレームの中央値、ms）:

| 画面 | 旧 エリア1 / エリア4 | 新 エリア1 / エリア4 |
|---|---|---|
| 1600×900（倍率 1.0） | 14.7 / 11.2 | 18.2 / 15.0 |
| 3840×2160（大画面高精細） | 74.6 / 59.9 | 78.6 / 76.6 |

- 4K の内訳（エリア 1、層を外した差）: 宇宙 約 24、にじみ 約 28、大陸 約 11（うち発光 7）、周辺減光 約 8、上の雲 約 5、演出 約 2。ソフトウェア描画では加算合成が特に遅い。GPU では同じ面積の通常の合成と同程度のはずだが、**実機では未計測**
- 焼いたキャンバスの合計（目安）: 900p で 20–30MB、4K で 51–59MB、iPad Pro 11 縦（1668×2388）で約 54MB。帯は見えている分＋先読みだけを持ち、通り過ぎたら捨てる
- 焼き時間（900p、3 分の自動プレイの合計から）: 空 約 120ms/エリア（1 区切り最大 12ms）、天体 約 28ms、帯 約 16ms/本（1 区切り最大 19ms）、スプライト全部 約 26ms。1 フレームの予算はプレイ中 3.5ms・導入中 7ms
- 3 分の自動プレイ（8 エリアを順に＋周回、900p）: エラー 0、JS ヒープ 5–10MB で横ばい、焼いた量 20–30MB で横ばい

## できていないこと・注意

- **実機（GPU のある PC の 4K、iPad）での 60fps は未確認**。ここでの数字はソフトウェア描画で、4K は旧版も新版も 60fps に届かない
- ソフトウェア描画では旧版より 1.05–1.35 倍重い。自動画質は遅いとにじみを切り、次に倍率を下げる
- デバッグの N キーや `g.scroll` の書き換えで飛んだ直後は、見えている帯をその場で焼くので 1 回だけ 100ms 前後止まることがある（通常の進行では先読みで間に合う。コアの撃ち逃しの巻き戻しでも起きうる）
- 影は「島の上かどうか」を点で判定している（縁をまたぐ影の形までは切っていない）
- 壊した標的の土台は暗い円として残る（焦げ跡と重なる）
- `desynchronized` は対応ブラウザだけで効く。効果は実機で未確認
- 検証中、並行作業中の shared/audio が読み込めない時間があったため、スクリーンショットと計測は旧版の音まわりを差し替えて行った（描画には関係しない）
- main.js に検証用の `window.__renderer`（`stats`・`_R.skip`・`_A`）を追加した
