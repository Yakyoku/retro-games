# SPEC — 確定事項・仮定・最終的な数値

## 1. 確定事項（依頼文から）

- 単独のスパイが屋上から潜入し、赤いドアの全書類を回収して最下層（1 階）の出口から脱出する。敵の全滅はクリア条件ではない
- 短いチュートリアル＋本編 30 階建て × 3 ステージ。2D 横視点と、3D 版は一人称 VR
- 昇降機は位置・乗降・上下操作のタイミングが攻略に影響する（瞬間移動メニューにしない）
- 残機制（体力ゲージなし）、ミス後は現在階の安全地点へ復帰（書類・得点は維持、敵弾を除去、約 2 秒の無敵）
- 2D と 3D で書類・得点・残機・クリア条件の意味を揃える
- 両版のトップに制作注記と非公式の表記

## 3. 仕組み（実装）

- 座標: x = ビル内の左右 0..24m、y = 足元の高さ（n 階の床 = (n-1)×3m）、z = VR の奥行き（2D では 0）
- 昇降路の開口: かごが居ない階では穴（落下は 3.6m までは無事 = 1 階ぶん）。かごの床と屋根はそれぞれ床として立てる
- **屋根の上で上昇すると挟まれる**（プレイヤーはミス、敵は 300 点の「昇降機による撃破」）。乗っている人は運ばれる（乗車でミスしない）
- 呼び出し: 穴の手前（縁から 1m）で ↑。自動運転のかご（第 2・3 ビル）は呼べず、動く前にチャイムと警告灯で予告
- エスカレーター: 上り口で ↓、下り口で ↑。乗っている間は射撃可・被弾あり。終点はかならず床の上
- 照明: ジャンプ中の射撃で落とせる（VR は銃で直接狙う）。落下で下の敵を倒す（300）／自分も当たるとミス。消えた所は暗く、敵の発見距離 55%・構え +0.3 秒。描画は最低 35% の明るさを残す
- 遮蔽物: 高さ 1.0m。弾を止める。2D では手前を通り抜け可、VR では奥側を回り込む
- 敵: 巡回 → 発見（同じ階・距離・明るさ）→ 構え（バイザーが光る）→ 射撃 → 再行動。型 0: 立ち撃ち／型 1: 低い弾も撃つ・撃たれるとしゃがんでかわす／型 2: 遮蔽物の陰に隠れて撃つ
- VR では低い弾を横移動（実際に動く・Y）でよける。弾は構え始めた時のプレイヤーの z に向かって飛ぶ
- 時間は 1/120 秒の固定刻み・1 フレーム最大 0.25 秒。弾は区間（前フレーム→今）で当たり判定（すり抜けなし）

## 6. 画面遷移・保存

ロード → タイトル（背景で自動演技）→ ステージ・難易度 → プレイ → 一時停止（再開・設定・操作方法・リトライ・タイトル）→ 結果 → 次のステージ → 全ステージ達成。残機 0 でゲームオーバー（リトライ・タイトル）。
リトライはそのステージの開始時の得点に戻し、残機は難易度の初期値。ハイスコアは保持。
保存キー `night-shaft:2d:v1` / `night-shaft:vr:v1`（設定・ハイスコア・クリア済みステージ）。2D と VR は別サイトなので共有しない。保存不可・破損時は既定値で遊べる。
