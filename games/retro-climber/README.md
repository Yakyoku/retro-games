# 鉄骨レスキュー 2D / VR（IRON SUMMIT）

この作品は Claude（Claude Code のクラウドセッション）で制作しました。

工事現場の鉄骨を、転がってくる樽をかわしながらジャンプとはしごで登り、最上階で巨大な類人猿「ゴンザ」から仲間の「ミナ」を救出するアクションゲームです。
1981 年ごろのアーケードの「樽をかわして登る」遊びに影響を受けた**オリジナル作品**で、キャラクター・面の配置・曲・効果音はすべて自作です（既存作品の名称・造形・楽曲は使っていません）。

## 遊ぶ
- 公開 URL: https://tekkotsu-rescue-yk.netlify.app/
- トップ（タイトル）で「2Dで遊ぶ」か「3D VRで遊ぶ」を選ぶ。プレイ中はポーズ（Esc／Start／右 B／画面右上 Ⅱ）から「2D⇄3D VR に切り替える」
  （今の面の最初から再開し、以後は練習扱い）
- 2D: デスクトップのブラウザー、iPad、Meta Quest Browser の通常画面
- 3D VR: Meta Quest 3 の Meta Quest Browser で上の URL を開き「3D VRで遊ぶ」。体験視点（一人称）と俯瞰の模型を設定・ポーズで切り替え
- WebXR の小さな検証ページ: https://tekkotsu-rescue-yk.netlify.app/experiments/01-webxr-probe/

## 操作
| | キーボード | ゲームパッド | タッチ | Quest |
|---|---|---|---|---|
| 移動 | ←→ / A・D | 左スティック・十字キー | 左のスティック | 左スティック |
| はしご | ↑↓ / W・S | 同上 | 同上 | はしごの前でグリップ（つかむ／もう一度で離す）＋左スティック上下（模型は上下だけ） |
| ジャンプ | Space | 下ボタン（A／×／B） | ジャンプ | 右 A |
| 道具・装置 | F | 左ボタン（X／□／Y） | 道具 | 右トリガー |
| ポーズ | Esc | Start | Ⅱ | 右 B |
| 回転 | — | — | — | 右スティック左右 30°（模型は模型の向き） |

## 面
チュートリアル（あとから再実行可）→ 第1面 鉄骨 → 第2面 搬送設備 → 第3面 昇降機 → 第4面 最上階（装置 ①〜④ を順に解除）→ 救出・エンディング → 結果

## 開発
```
GAME=retro-climber VARIANT=all node tools/build-game.js   # リポジトリのルートで。dist/ に出る
node --test tests/*.test.js                                # 作品フォルダで（論理・保存・入力・曲データ）
node tools/check.js                                        # 静的点検
```
- デバッグ: `?debug`（FPS・内部解像度・描画数。I 無敵／N 次の面／K ミス／T 残り 5 秒）、`?start=1〜4|tutorial`、`?debug&calm&autoplay&speed=8`（危険を止めて自動プレイ。画面遷移の確認用）
- 構成・判断・調整値・未確認事項は CLAUDE.md、音は SOUND.md
