## 依頼文 §14〜15（複数の Unity の同時制作）について

Unity を使っていないため対象外。このリポジトリでの分離は次のとおり（**分離の設定のみ。同時に動かしての検証はしていない**）。

- 作品のファイルは games/aegis-relay/ の中だけ。ルートの netlify.toml・tools/build-game.js・他の作品は変更していない
- ビルドの出力は games/aegis-relay/dist（作品ごと）とルートの dist（Netlify のビルドの中だけで使う）
- Netlify はサイト ID を指定してデプロイ（netlify-sites.json）。「最後にリンクしたサイト」には頼らない
- ブラウザの保存領域は Netlify のサイトごとに別（2D と VR で記録は共有されない）
- サーバーは立てていない（検証は Playwright のリクエスト差し替えで dist を返した）。ポートの競合はない
