# CLAUDE.md — 鉄骨レスキュー（games/retro-climber/）

この作品は Claude（Claude Code のクラウドセッション）で制作しました。決定事項・調整値・判断ログ・検証記録・未確認事項をここに残す。

## 目的
工事現場で樽をかわし、ジャンプとはしごで上へ進み、巨大な敵を退けて救出するアクション。1 つのアプリで 2D クラシックと 3D VR（WebXR・Meta Quest 3 単体）を切り替える。
対象は制作者本人（大人）。PROCESS.md §9 は適用しない。

  Netlify はリポジトリ連携ではなく CLI のアップロード＆ビルドなので、main に入っていなくても公開できる
- 2026-11-12 2D の判定: 3D 物理を使わず、自前の 2D 判定（足場は傾いた線分＋厚み、樽は円、人は箱）。全モードで同じ論理。描画は 3D モデルを正投影（10° 見下ろし）
- 2026-11-12 足場は下から通り抜けない（頭が下面に当たる＝bonk）。上から着地する一方向。はしごだけが上下の階をつなぐ
- 2026-11-12 復帰点: 面の開始時（やさしいは中間地点でも）にスナップショット（樽・木箱・ボルト・ロボ・ハンマー・装置・残時間・得点・乱数）を取り、ミスで戻す。
  残機だけは減った値のまま。得点は復帰点の値に戻る（ミスを繰り返して稼げない）。戻した残時間が 45 秒未満なら 45 秒にする（時間切れの連続を避ける。仕様からの調整）
- 2026-11-12 VR 一人称の縮尺は 1.85 倍（主人公 0.95m → 約 1.75m）。プレイヤーの目の高さ＝主人公の目の高さ。主人公の当たりの高さは目より上なので、通常の操作でカメラが梁に入らない
- 2026-11-12 VR 一人称のはしご: グリップで「つかむ」、もう一度で「離す」（握り続けなくてよい。手の疲れ対策）。離すと落下。模型の視点ではスティックの上下だけで昇降（仕様どおり）
- 2026-11-12 スナップ回転は模型でも 30° 刻み（連続回転より酔いにくい）。模型の縮尺は 1/13（約 1.23m 四方）、台の高さ 立位 0.86m／座位 0.62m＋補正
- 2026-11-12 チュートリアルでは残機を減らさない。課題を 1 つ終えるごとに復帰点が進む。ハンマーは「道具」の課題になってから置く
- 2026-11-12 入力の重複防止: 全系統（キー・パッド・タッチ・XR）を合わせた状態の立ち上がりで「押した瞬間」を 1 回だけ作る。キーの自動リピートは無視。
  フォーカス喪失・非表示・パッド切断・XR の中断で全部離し、押したまま戻っても一度離すまで無視。XR 中は通常のゲームパッドを読まない

## 画質
- 大画面: 画質「自動」は画面の実ピクセル幅が 3000 以上なら Ultra（描画倍率＝devicePixelRatio、最大 3。影 4096）、それ以外は High（倍率 ≦2、影 2048）、Standard（≦1.25、影 1024）。
  自動のときだけ、プレイ中に 48fps 未満が 2 秒続くと倍率を 0.85 倍ずつ下げる（下限 0.6）。MSAA（antialias）、テクスチャはミップマップ＋異方性 8
- 文字・HUD はすべて DOM（4K でもにじまない）。`?debug` か設定「FPS 表示」で内部解像度・倍率・描画数・p95/p99 のフレーム時間を表示
- テクスチャ解像度: 樽の板 1024×512、ふた 512、塗装鋼 512、縞鋼板 256、布・毛の法線 256（繰り返し）、遠景 4096×1024（Standard は 2048×512）
- Quest High: 解像度倍率 1.2・フォービエーション 0.5・72Hz（設定で 90Hz・Standard＝倍率 1.0・フォービエーション 1.0）。マルチビューは three r187 の WebGLRenderer が対応していないので未使用
- VR の舞台はクラウドの描画が遅いため、Quest 実機での fps・フレーム時間は未測定
