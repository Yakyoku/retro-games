# AUDIO_REFERENCE.md — 音の参照・方針・対応・比較結果

## 結論（先に）
- **原作の曲・効果音の「再現」は行っていない。** 原作（日本版アーケード「グラディウス」1985）の楽曲・効果音は著作物で、
  耳コピ・打ち込みによる再現音源でも、利用許諾なしに公開サイトへ収録することはできない。依頼文の「参考試聴できることと、公開物へ収録できることを区別する」に従い、収録しない判断をした。
- **原作の音源を試聴・比較していない。** クラウドのコンテナには音声出力が無く、使用できる原音素材（依頼者提供の音源など）も無かった（Google Drive の検索 0 件）。
  よって「原音と同一」「忠実に再現」と言える音は**ひとつも無い**。
- 実施したのは、確認できた**基板の音源構成**をソフトで模擬し（下記の出典）、その上で**全曲・全効果音を新規に作った**こと。
  当時の書き方（明るい矩形波の旋律、波形メモリのベース、PSG のアルペジオ、ノイズの打楽器、フレーム単位の進行、モノラル）に寄せている。

## 模擬した構成（shared/audio/）
| 部品 | 模擬 | 用途 |
|---|---|---|
| PSG-A（AY-3-8910 相当） | 矩形波 3＋共有ノイズ（17bit LFSR）＋エンベロープ、12bit 周期、AY の対数音量表、クロック 1.789772MHz/16 | 曲（旋律・和音・ノイズ打楽器） |
| 波形メモリ 2 音（K005289 風） | 32 サンプル × 4bit、12bit 周期、4bit 音量 | 曲（ベース・対旋律） |
| PSG-B（2 個目の AY-3-8910 相当） | 同上 | 効果音専用（曲の音を奪わない） |
| 出力 | 2 段ローパス約 8kHz → 直流カット → ピーク抑制、**モノラル** | 既定の「忠実」モード |
| 音声合成チップ（VLM5030） | **模擬していない**（音声は使わない） | — |

アレンジモード（設定、既定 OFF）は軽いステレオの広がりとエコーだけを足す。VR でも音はモノラルのまま（空間化はしていない。BGM・UI 音を空間化しないという方針にも合う）。効果音の控えめな空間化は未実装。

## 効果音とイベントの対応（すべて新規作成）
| 効果音 | 鳴る時 | 優先度の考え方 |
|---|---|---|
| shot / double / laser | 1 回の斉射につき 1 回（オプションが何機でも 1 回） | 低。同じ音は重ねず頭から鳴らし直す |
| missile | ミサイル発射（全機で 1 回） | 低 |
| capsule（= gauge） | カプセル取得 | 中 |

| shield_on / shield_hit | シールド取得 / シールドで防いだ | 中 |

| explode_s / explode_m | 小型・中型の撃破 | 中 |

| ring | 石像のリング弾 | 低 |
| warning | ボス接近・フェーズ移行 | 高 |

## 比較・計測の結果（機械による確認のみ）
`node tools/render-audio.js` と `node --test tests/audio.test.js` の結果（2026-11-12）:
- 全曲・全効果音で NaN なし、0.99 を超える標本 0、ピーク 0.29〜0.61（曲）、直流 4e-6 以下。
- 最大の同時発音（第 7 面・ボス・最終ボスの曲＋効果音 3 チャンネルを毎フレーム）でもピーク < 1.0（アレンジ ON/OFF とも）。
- 全トラックの長さ・ループ点が一致、全小節がちょうど 96 tick。音域は周期レジスタの範囲内。
- 一時停止中は曲が無音（1e-5 未満）、再開後 120 フレームのレジスタ値が止めなかった場合と一致（位置ずれなし）。
- 同じフレームに同じ効果音を 1・2・5 回呼んでも出力は同一（オプション 4 機で音割れしない）。
- 旋律とベースの拍ごとの音程の協和の点検で、第 1 面の不協和な経過音を 1 つ修正。
- スペクトル重心 2.5kHz（第 5 面）〜3.2kHz（第 1 面）。

**人の耳での試聴・原音との聴き比べ・ゲーム内の BGM/効果音の比率の聴感確認は未実施**。公開版を実際の端末で聴いて確認する必要がある。
