クレジット・素材と音について

本ゲームはClaude Codeのクラウドセッションで制作しました。

企画・制作の依頼: 藤田さん（個人の制作物）。設計・実装・3D モデル・曲・効果音・掛け声の合成・検証は Claude Code（Anthropic の AI コーディングツール）がクラウド上で行いました。この表示は「Claude Code を使って作った」という説明で、Anthropic による公式の認定や共同開発を意味するものではありません。

着想元

『クレイジー・クライマー』（日本物産、1980 年、アーケード）の「左右の手を別々に動かしてビルを登る」「窓の開閉・落下物・鳥を読んでよける」遊びに着想を得ています。原作の画像・キャラクター・曲・音声・名称は使っていません。仮の題名「Sky Climber VR」も新規です。

音について（原音との関係）

原作の基板の音源構成（AY-3-8910 と、ROM に入った短い声のサンプル）は MAME のドライバー資料で確認し、その「仕組み」（矩形波 3 声とノイズ、16 段の対数音量、60 分の 1 秒ごとの音量操作、低いサンプリングの声）を再現しました。原作の曲（既成曲の引用を含む）や効果音・声そのものは使っておらず、聴き比べ（原音比較）も行っていません。すべて「当時の雰囲気を踏まえた新規の音」です。詳しくは サウンドテスト を参照してください。

キャラクターについて

主人公「ソラ」、窓の住人（おやじ・おばちゃん）、カモメ、ヘリのパイロットは新規のデザインです。参考作品の資料から「小さく映っても役割が分かる」「少しコミカル」「手足の動きの誇張」という方向性だけを取り入れ、配色・形は独自に決めました。
