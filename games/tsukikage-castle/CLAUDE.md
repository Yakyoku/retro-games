# CLAUDE.md — 月影の魔城（games/tsukikage-castle/）

この作品は Claude（Claude Code のクラウドセッション）で制作しました。決定事項・判断ログ・未解決をここに残す（次のセッションはまずこれを読む）。

## 目的
1985 年アーケード版『魔界村』の怪奇性・ユーモア・明快なアクションを参考にした**非公式の新規作品**を、
2D Web 版（デスクトップ・タブレット・スマホ）と 3D / VR Web 版（通常ブラウザの三人称 3D ＋ Quest 3 WebXR）で作る。
原作のキャラクター・絵・楽曲・面構成は再現しない。対象は大人（PROCESS.md §9 は適用しない）。

## 構成の要点
- `shared/core.js` が唯一のゲームロジック（60Hz 固定・決定的・描画に依存しない）。2D と 3D はこれを描くだけ
- `shared/stages.js` の Builder でタイル格子（0 空・1 固い・2 片側足場・3 はしご・4 溶岩・5 水）と敵・アイテム・移動床・炎の柱・中間地点・ボスの間を組む
- `tools/reach.js` が実際の core で到達探索 → ステージを直したら必ず `node tools/reach.js` と `node --test tests/*.test.js`
- 画面遷移・メニュー・保存・入力は `shared/app.js`（2D/3D 共通）。HUD・メニューは `shared/ui.js` が Canvas に描く（3D 通常は重ね、VR は板に貼る）
- 骨格ポーズは `shared/anim.js`（2D の art.js と 3D の models.js が同じポーズを使う）。歩幅 STRIDE = 4·脚長·sin(振り幅) で足が滑らない

### 2026-11-12 30 項目の改善（藤田さんの iPad の画面写真から）
依頼: タッチの丸が大きすぎて邪魔・画面をもっと広く使う・キャラクターをプロが作ったような滑らかなものに。
- タッチ（1〜6）: 大きさを画面の短い辺に合わせる（--u = 11vmin、46〜76px）。スティックは触れた場所に出て、離すと薄い目印だけ。ボタンは半透明・押すと縮む。
  ポーズは右上の角（他のボタンと重ならない）。背の低い画面は小さめの配置。HUD は右上のポーズボタンの分をあける
- 全画面（7〜9）: 16:9 の黒帯をやめ、画面の形に合わせて見える範囲を広げる（最低 24×13.5u、最大 32×18u。背の低い画面は 15% 寄せる）。
  core に setView を追加し、敵の出現・カメラ・弾の消去も見える範囲に合わせた（端での急な出現を防ぐ）。カメラの先読みを滑らかに
- 騎士（10〜17）: play2d/figures.js で作り直し。先細りの丸い手足、曲面の胸当て・草摺・3 枚重ねの肩当て・膝と肘の当て・籠手・板の靴、
  3 段の陰影＋月光の縁取り＋鏡面の光、面頬とのぞき穴・鶏冠・鋲・ばねで揺れる 3 本の羽根、7 点の鎖で揺れるマント（体の前へは回らない）、
  状態の切り替えをポーズの補間でなめらかに、鎧なしは上着のしわ・揺れる髪・驚いた顔
- 魔物（18〜22）: 8 種を同じ描き方で作り直し（亡者のあばらと顎、骸骨の骨の形と顎、夜魔の膜の翼と尾、牙獣・術者・跳ね鬼・鉄塊鬼・石像）。
  ボスは別のキャンバスに描いて月光色の影絵を左上にずらして重ね、縁を光らせる（予告の線が出る間は直接描く）
- 効果（23〜27）: 接地の影、着地・振り向き・足音の土煙、投げた武器の軌跡、命中の輪と放射線、テーマごとの漂う粒子（蛍・火の粉・しずく・塵）
- 環境（28〜30）: 地面の上端の面取りの光と揺れる草、画面下の手前の暗い影、火・溶岩・松明の暖色の光

### 2026-11-12 自己点検による 10 項目（プロの 2D アクションの水準と比べて最も見劣りする所から）
1. ボス 6 体を新しい描き方で作り直し（play2d/bosses.js）: 墓守の頭巾・つぎはぎ・鬼火のランタン・錆びたシャベル、魔女の乱れ髪と曲がった帽子と裂けた裾、
   沼獣の膜の背びれ・ぬめり・飛び出た目・ひげ、守護者の 3 段の羽根、炎騎士の溶岩の割れ目と燃える剣、魔城の主の赤い裏地・骨の冠・多眼・渦巻く宝珠
2. 地面を「描いた地形」に: 6×6 タイルの区画ごとに焼いて使い回す（最大 80 区画）。深さで暗くなる継ぎ目なしの塗り、埋まった石・根・骨・結晶、
   煉瓦の段（城のテーマ）、張り出す縁と月光、横の内側の影、下の庇と垂れる根、木目と釘の板、縄で結んだはしご
3. 小物: 墓石（3 形・苔・ひび・刻んだ十字・台座・月光の縁）、錆の柵
4. 背景の奥行き: 近景の層（中景を拡大して暗く塗り直す。壁で埋まるテーマには使わない）、霞の帯、回る月光の筋、月の前を流れる雲
5. 動きの誇張: 騎士は上昇で縦に伸び着地でつぶれる、被弾した敵がのけぞる、倒した敵は霊の炎になって昇る
6. 色調: 上は冷たく下は暖かいグラデーションを焼き込み
7. 武器・アイテム（play2d/fx.js）: 木目の柄と鋼の穂先、斧の回転の残像、本物の炎、金具の宝箱、光の柱の中の壺の武器、鎧
8. 敵の攻撃: 芯・光輪・尾の弾、渦の魔法弾、ジグザグの雷、ゆらぐ光線、破片が飛ぶ衝撃波、水滴
9. HUD: ゴシック調の飾り枠（角の菱形）、数え上がる得点、拾った物・中間地点・鎧破壊の知らせ、飾り付きのボス体力帯
10. タイトル: 丘で月を見上げる騎士（揺れるマントと羽根）、流れる霧、彫り込んだ金属の題字と金の飾り線、項目の飾り枠
