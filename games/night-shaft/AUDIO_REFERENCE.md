# AUDIO_REFERENCE — 音の方針・音源・イベント対応表（v3, 2026-11-13）

既存作品の楽曲・効果音の再現は行っていない（原作音源の参照・A/B 比較もしていない）。すべてこのセッションで作曲・音作りしたオリジナル。
v3 で「チップ音源風」から、現代のアーケードゲームとして通用するシンセサウンドへ作り直した。

## サウンドの 30 項目（v3）

1. 新しいシンセエンジン（`shared/audio/synth2.js`）: 帯域制限ノコギリ波・PWM 矩形波・三角波・正弦波・2 オペレーター FM・ユニゾン（スーパーソウ）・ノイズ
2. 1 音ごとの ADSR と状態変数フィルター（エンベロープ・レゾナンス・キートラック）、ピッチエンベロープ・ビブラート
3. ステレオ（ユニゾンの左右の広がり・パン）
4. リバーブ（Freeverb 型、曲ごとに部屋の広さと減衰）
5. テンポ同期のピンポンディレイ
6. キックによるサイドチェイン（パッド・ベースが拍に合わせて沈む）
7. マスター: 低域の濁りを切るハイパス・音量の正規化（約 -15 LUFS）・コンプレッサー・ソフトクリップ
8. 合成ドラム（ピッチが落ちるキック＋クリック、胴鳴りのあるスネア、多重クラップ、金属的なハット、タム、クラッシュ、シェイカー）
9. タイトル曲（D マイナー・96 BPM・映画的なシンセウェーブ、16 小節）
10. 第1ビル／訓練棟の曲（A マイナー・124 BPM・スパイ風ファンクハウス、FM エレピのカッティング）
11. 第2ビルの曲（E マイナー・136 BPM・冷たいエレクトロ、FM ベルの旋律）
12. 第3ビルの曲（C マイナー・148 BPM・デチューンしたリースベースとスタブ）
13. 緊張の層: 各ステージ曲の 2 本目の音源（シェイカー・ブラス・アルペジオ・タム等）を同時に鳴らし、同じ階の敵に見つかっている間だけ 0.8 秒かけて上げる
14. 潜入開始のジングル（ノイズのライザー → 和音とサブベースの一撃）
15. 書類取得のジングル（FM ベルのアルペジオ）＋紙をめくる音
16. クリアのファンファーレ・全ステージ達成の曲・ミス・ゲームオーバー
17. 曲は事前にレンダリングして MP3 で配信（Quest でも開始時に待たない）。ループは「末尾 1 秒＋曲＋先頭 1 秒」で書き出し、エンコーダーの遅延に関係なく継ぎ目が出ない
18. 主人公の銃声: クリック＋胴鳴り＋低い衝撃＋スライドの金属音＋尾の 5 層
19. 敵の銃声: 低く重い別の音色（聞き分けられる）
20. 構えの予兆音: 撃鉄を起こす 2 つの金属音＋バイザーの充電音
21. 弾が近くをかすめる音（ウィズ）
22. 薬莢が床に落ちる音（射撃の 0.32 秒後）
23. 撃破の衝撃音と、0.5 秒後に体が倒れる音
24. 足音（4 種のかかと→つま先、再生速度をわずかに揺らす）。主人公は走りの足の着地に、近くの敵は歩きの着地に同期
25. 照明: ガラスの割れる音と火花 → 落下して砕ける多数の破片
26. エレベーター: 継電器とモーターの立ち上がり、走行のうなり（ワイヤーのきしみ入りループ）、到着のブレーキと FM の 2 音チャイム、自動運転の警告音
27. 通常ドア: カードリーダーの電子音と解錠 → 空気圧の開閉音。書類部屋のドアの取っ手
28. 環境音（ステージごと 11.5 秒のループ）: オフィス＝空調と遠くの車、研究棟＝空調と機械の電子音、警備棟＝雨と遠雷
29. 空間の表現: 効果音の左右の定位、別の階の音はこもらせて小さく（ローパス）、効果音に畳み込みリバーブ（棟ごとに量を変える）
30. メニューの補助音を FM の柔らかい音に（設定で消せる）

## イベント対応表（`playGameEvents`、2D・VR 共通）

| 出来事 | 音 |
|---|---|
| 射撃 | shot ＋ 0.32 秒後に shell |
| 敵の射撃 / 構え / 発見 | eshot / windup / spot（別の階なら、こもらせる） |
| 敵の弾が 0.9m 以内を通過 | whizz |
| 撃破 | hit（キックは kick、かごで挟むと crush）＋ 0.5 秒後に bodyfall |
| ジャンプ・着地 / 足音 | jump・land（落下の高さで音量）/ step0〜3 |
| 照明 | lightHit → lightCrash |
| かご | carStart・走行ループ・carStop・carPass（乗車中）・carWarn・carLimit |
| 呼び出し / 出現の予兆 / 出現 | call / doorWarn / doorOpen |
| 書類 | docGrab ＋ doc ジングル（BGM を 30% に下げて重ねる） |
| 遮蔽物に命中 / 書類不足 / 横よけ | bulletCover / needDocs / dodge |
| ミス・クリア・ゲームオーバー | miss・clear・gameover（BGM を止める） |
| 同じ階で見つかっている | 緊張の層を上げる |
