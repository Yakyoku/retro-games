# AUDIO_REFERENCE

この作品は Claude（Claude Code のクラウドセッション）で制作しました。

## 依頼文の「原音に忠実な再現」について（未実施・理由）
依頼文は、アーケード版「リブルラブル」の曲・効果音を原音に忠実に再現することを最優先としていたが、**これは行っていない**。
原作の旋律・効果音を耳コピーや解析で作り直して公開することは、権利者の許諾がない限り著作物の複製にあたるため、制作時に利用者へ伝えたうえでオリジナルの音で作った。
参照した原作の資料・音源・映像はない（調べていない）。原作の音と発音イベントの対応表も作っていない（原作の仕様を創作しないため）。

## 実際の音（すべて自作）
- 音源: パルス波（デューティ 12.5%・25%・50%、PeriodicWave の 63 倍音まで）・三角波・ノイズ（16bit の xorshift で作った 1 秒のループ）
- 打楽器: キック（正弦波 150→42Hz）、スネア（ノイズ＋帯域 1.9kHz）、ハット（ノイズ＋高域 7kHz）
- 残響・コーラス・ステレオ拡張・コンプレッサーは使っていない
- 曲（自作 MML）: タイトル・春の庭（1〜4 面）・夕暮れの池（5〜8 面）・月夜の花園（9〜12 面）・ボーナス・強化中・ジングル（開始・クリア・ミス・ゲームオーバー・ボーナス終了・エンディング）

## ゲームイベント → 音（2D と VR で同じ表）
| イベント（共通コア） | 音 |
|---|---|
| stage（面の開始） | ジングル「開始」 |
| go（プレイ開始） | 面のテーマ曲（ボーナスはボーナス曲） |
| wrap / unwrap（杭に掛かる・外れる） | 短い上昇音・下降音 |
| capture（捕獲） | 「パチン」（ノイズ）＋捕まえた数だけ上がる音階（最大 8 音）。空振りは短い音 |
| plant（回復） | 三角波の 4 音 |
| power / powerEnd | 上昇 6 音と強化曲／下降 3 音とテーマ曲に戻る |
| hint / chest / gem | 2 音の問いかけ／5 音のチャイム／数に応じて高くなる音 |
| miss | 衝撃音 → 曲を止めてジングル「ミス」 |
| clear / bonusStart / bonusEnd / gameover / complete | それぞれのジングル |
| メニュー（移動・決定・戻る） | 短い音 |

## 再生の仕組み
- 曲は AudioContext の時計に 0.18 秒先まで予約する（25ms ごと）。テンポ・音程は描画フレームに依存しない
- 効果音はゲームの tick で確定したイベントから 1 回だけ鳴らす（描画フレームでは鳴らさない）。同じ効果音の 40ms 以内の連打はまとめる
- 同じ曲の二重再生をしない。一時停止で曲を止めて位置（拍）を覚え、再開で同じ位置から続ける。タブ非表示・VR の追跡喪失では AudioContext ごと止める
- 最初の操作（タップ・キー・メニュー決定）で AudioContext を開ける（iOS Safari・Quest 用に無音を 1 回鳴らす）
- 音量: マスター・音楽・効果音・消音を個別に保存。「追加の環境音」は作っていない（標準モードで勝手に重ねない）
- VR でも 2D と同じ音（頭の動きで BGM や効果音が動かない・距離減衰・残響・ドップラーなし）。任意の「空間演出モード」は作っていない（効果のない設定を置かないため、設定項目も出していない）
