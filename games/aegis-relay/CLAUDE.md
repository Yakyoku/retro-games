# CLAUDE.md — AEGIS RELAY（games/aegis-relay/）

この作品は Claude（Claude Code のクラウドセッション）で制作しました。決定事項・調整値・判断ログ・未解決をここに残す。

## 目的
縦スクロールシューティングの遊びの仕組み（縦スクロール、空と地上の標的、支援機との合体、隠しボーナス、周回、高得点狙い）を持つ
**オリジナル作品**を、2D（PC・タブレットのブラウザ）と 3D（通常画面＋ Meta Quest 3 単体の WebXR）で、同じルールのまま作る。
対象は制作者本人（大人）。PROCESS.md §9（子ども向け）は適用しない。

- 2026-11-12 依頼文には作品フォルダの指定がなかった。新しいフォルダ games/aegis-relay を作った（ルートの CLAUDE.md では 7 作品の共有だが、実際にあったのは bio-hshooter だけ）
- 2026-11-12 指定ブランチ claude/beautiful-meitner-5vj67l で作業し、ルートの CLAUDE.md の約束（main に直接 push）に従って main にも push する
- 2026-11-12 Netlify は依頼どおり 2D・3D の 2 サイトに分けた（bio-hshooter は 1 サイト）。入口ページ（index.html）は 1 つで、ビルド時の data-variant でカードを切り替える
- 2026-11-12 ルールは shared/sim.js の 1 つだけ（60Hz 固定・決定的・乱数は状態に持つ）。2D・3D は表示と入力だけ。判定は盤面の 2 次元座標のみ
- 2026-11-12 エリアは area-gen.js のレシピ（固定の乱数の種）から組み立てる → 毎回同じ地形・編隊で、覚えて上達できる。周回で変わるのは速さ・射撃間隔・追加の機数だけ
- 2026-11-12 エリアコアを撃ち逃したら 300u 手前へ戻して再接近。最初の実装では耐久が満タンに戻り、30 分の自動テストで永久に進めなかった → 与えた損傷を残すように修正
- 2026-11-12 ポーズからの再開直後に被弾することがあった（VR のエミュレーターで確認）→ 再開時に 1 秒無敵＋0.5 秒は敵が撃たないようにした
- 2026-11-12 2D は Canvas 2D。描画バッファは表示の実寸×DPR×画質倍率。機体・敵はベクターの絵を、いまの倍率でキャッシュに描き直す（4K でにじまない）。
  4K で地面が平坦に見えた → 表示倍率ちょうどの解像度で焼いた 128 単位の地面の模様（粒・まだら・ひび・小石）と、縁の内側の陰を追加
- 2026-11-12 文字は DOM（HUD・メニュー）。日本語フォントは M PLUS 1p（OFL）の japanese / latin の woff2 を fonts/ に同梱（依存は追加していない）
- 2026-11-12 3D の戦域は盤面の長方形のクリップ面で切り抜く（星空と奈落は切らない）。浮遊大陸は押し出しの上面＋だんだん細くなる 3 段の岩。
  敵弾は暗い縁・桃色・白い芯の 3 重の球で、奥行きテストを切って地形や敵に隠れないようにした
- 2026-11-12 通常画面の 3D は最初、真上に近い視点で厚みが見えなかった → 約 41° の見下ろしに変更
- 2026-11-12 VR: カメラとコントローラーは基準空間の直下、戦域とメニューは stage の下。再センタリングは stage を頭の位置と向きに合わせる（カメラを stage に入れると頭ごと動いてしまう）。
  最初は戦域が目の前に近く大きすぎた → VR では幅 0.82m、1.2m 先、目の高さより 0.5m 下
- 2026-11-12 XR 中はページの blur でポーズしない（Quest のブラウザは XR 中に blur が来ることがある）。代わりにセッションの visibilitychange（hidden / visible-blurred）でポーズ
- 2026-11-12 音は Web Audio で、帯域制限した矩形波（PeriodicWave）＋ LFSR ノイズ。曲は自作 MML。効果音が鳴る間は曲の ch2・ch3 を譲る（声の数が決まっていて音割れしない）
- 2026-11-12 録音した音の解析で、ループ 2 周目が 20〜30ms ずれて見えた → 模擬の AudioContext で全音符の発音時刻を照合し、誤差がないことを確認（録音経路の取りこぼしと判断）
