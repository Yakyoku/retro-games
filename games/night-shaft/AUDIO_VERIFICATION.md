## Web ビルドでの再生確認（Playwright・ヘッドレス Chromium）

| 確認 | 結果 |
|---|---|
| 公開 URL の 2D 版で、クリック後 AudioContext が running | 確認（デスクトップ・iPhone・iPad の模擬で running） |
| 曲を描き終える前にゲームを始めた時、BGM が鳴らない不具合 | 発見して修正（全曲を描き終えた後に、待っている曲を再生） |
| VR（IWER 模擬）で射撃時に shot が再生キューに入る | 確認（4 回撃って playLog に sfx:shot 4 件） |
| 開始ジングルが未準備のままステージを始めた時もステージ BGM が始まる | 発見して修正。再生記録: jingle:start → bgm:stage |
| 一時停止→再開で BGM が二重にならない | 再生記録で確認（再開後の bgm:stage は 1 件。前の BGM は停止済み）。聴取は未実施 |
