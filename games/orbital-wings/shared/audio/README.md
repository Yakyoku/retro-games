# ORBITAL WINGS の音

ブラウザの中で音を合成するソフト音源です（録音素材・外部サービス・生成 AI は使っていません）。
曲と効果音はすべてこの作品のために作ったもので、**既存のゲームの曲（旋律）や効果音は写していません。**

音源は 2 つあり、設定の「音源」で切り替えます。

| 音源 | 中身 | 既定 |
|---|---|---|
| **モダン** | 4 オペレーター FM ＋仮想アナログ（鋸・矩形・PWM・スーパーソー・波形メモリ）＋合成ドラム。ステレオ、残響とテンポ同期ディレイ、サイドチェイン、マスター処理 | ○ |
| **レトロ音源** | 1985 年ごろの業務用基板の音源のつくり（PSG×2＋波形メモリ 2 音）の模擬。モノラル・残響なし。従来のまま | |

## つくり

| ファイル | 役目 |
|---|---|
| `audio.js` | ゲームから使う窓口 `AudioEngine`（AudioContext は 1 つ。AudioWorklet、使えなければ ScriptProcessor） |
| `worklet.js` | AudioWorklet。`core.js` をオーディオスレッドで回す |
| `core.js` | `SoundCore`: モダン／レトロの切り替え（切り替え時は 0.4 秒重ねて消す） |
| `modern.js` | モダン音源 `ModernSynth`（声・打楽器・効果音・残響・ディレイ・マスター・曲の進行）。ブラウザ API を使わないので Node でも動く |
| `patches.js` | モダン音源の音色・波形メモリ・打楽器の設定 |
| `songs2.js` | モダン音源の曲（全 14 曲の再編曲）。和音名と型から和音の層・分散和音・低音・打楽器を書き出す |
| `sfx2.js` | モダン音源の効果音（層の重ね合わせ）と、レトロ音源への読み替え表 |
| `mml.js` | 曲の記法（MML 風）→ tick 単位のイベント列。和音 `{c e g}`・定位 `P`・フィルター `F` を追加 |
| `chip.js` `songs.js` `sfx.js` | レトロ音源（PSG・波形メモリの模擬）とその曲・効果音 |

### モダン音源の信号の流れ

```
曲の声（最大 32）─┬─ サイドチェインを受ける束（低音・和音）─×キックで下げる─┐
                 └─ 受けない束（旋律・分散和音・打楽器）────────────────────┼─ 曲の音量・フェード ─┬→ 残響（FDN 8 本）
打楽器（合成 9 種）──────────────────────────────────────────────────────┘                       ├→ ディレイ（ピンポン、テンポ同期）
効果音の声（最大 48 層・12 個）─ 効果音の音量 ────────────────────────────────→ 残響・ディレイへも  │
   曲＋残響＋ディレイ → 高域の持ち上げ → ローパス（一時停止・切り替え）→ ＋効果音
   → 直流カット → バス圧縮（2:1）→ ソフトクリップ → 先読みリミッター（2.5ms、上限 0.85）→ マスター音量
```

- 制御は 64 標本ごと（48kHz で 1.3ms）。曲の進行は tick（4 分音符 = 24）単位で、tick の境目は標本の精度で合わせる。
- 音の計算（`renderStereo`）の中では配列・オブジェクトを作らない（状態は作成時に確保）。同じ操作なら毎回同じ音（乱数は決まった列）。
- 効果音は専用の声を使うので、曲の声を奪わない。効果音どうしは優先度で奪い合う（高い音が低い音を止める。ミス・警告・ボスの音は必ず鳴る）。

## ゲームからの使い方

```js
import { AudioEngine } from './shared/audio/audio.js';
const audio = new AudioEngine();
startButton.addEventListener('pointerup', () => audio.unlock());     // 最初の操作の中で
audio.playMusic('stage1', { restart: true, lead: true });  // lead: 開始ファンファーレから切れ目なく面の曲へ
audio.playMusic('boss', { fade: 0.15 });                    // 前の曲をフェード＋ローパスで消してから
audio.playMusic('gameover', { mode: 'tape', fade: 0.9 });   // テープを止めるように落としてから
audio.stopMusic({ fade: 0.7 });
audio.sfx('explode_m', { pan: -0.3 });                      // pan: 画面の左右（-1〜1。ゲームは ±0.5 まで）
audio.sfx('capsule', { step: 3 });                          // step: ゲージの位置（音階が上がる）・シールドの残り
audio.setIntensity(2); audio.setLayer('danger', true);      // 動的な曲: ボスの体力・フェーズ、残機が最後
audio.setEngine('retro');                                   // 'modern' | 'retro'
audio.setPaused(true);                                      // モダン: 曲をこもらせる（止めない）。レトロ: 止めて消す
```

`unlock()`・`playMusic(id,{restart})`・`stopMusic()`・`sfx(name)`・`setVolumes()`・`setMuted()`・`setPaused()`・`suspendForHidden()`・
`resumeFromHidden()`・`state`・`musicPosition()` は従来どおり使えます（`setArrange()` は廃止。呼んでも何もしません）。

オプションの弾は音を足しません。`option_shot` という音は無く、オプションが何機いても 1 回の斉射につき `shot`（`double` / `laser`）を 1 回だけ鳴らします。
音源側でも、同じ名前を同じフレームに何度呼んでも 1 回分で、同じ名前は重なりません。

## 曲の足し方・直し方（モダン音源）

1. `songs2.js` の `song({...})` に節（section）を並べる。節には和音名（`'A'` `'C#m'` `'F|G'`）と旋律（小節ごとの MML）を書き、
   和音の層・分散和音・低音・打楽器は型（`ARP` `BASS` `DR`）の名前で指定する。ループする曲は `loopAt` に戻る先の節の番号。
2. `node --test tests/audio.test.js`（記法・小節・トラック長・調・音域・音量・ピーク）。
3. `node tools/render-audio.js --only <id>` で数値を見る（ラウドネスが -15 LUFS ±1.5 から外れたら `trim` で合わせる）。

## 点検と試聴用の書き出し

`node tools/render-audio.js` が全曲・全効果音を 48kHz ステレオで作り、ピーク・真のピーク・ラウドネス（BS.1770）・オクターブ帯域・左右の相関・
直流・クリップ・ループの一致・調の中の音の割合・旋律と和音の協和・計算時間を表にし、`audio-masters/` に .ogg と `report.json` を書きます
（WAV も書きますが git には入れません）。`--no-write` で点検だけ、`--retro` でレトロ音源の書き出し。
ゲーム本体はこれらのファイルを使いません（その場で合成します）。
