# ART_GUIDE — キャラクター・配色・地層・UI

この作品は Claude（Claude Code のクラウドセッション）で制作しました。造形はすべてオリジナルです（原作のキャラクター・画像の抽出や模写はしていない）。

## 方針

1980 年代前半のナムコ作品のような「小さく表示しても役割が瞬時に分かる、親しみやすくユーモラスな造形」を、輪郭・顔・道具の役割分担と演技で表す。
恐怖・残酷・写実・軍装には寄せない。2D はベクター描画（`shared/sprites2d.js`）、3D はプリミティブの組み立て（`shared/models3d.js`）で、同じ配色と特徴を使う。

3D の支えは木の枠（柱 2 本・梁・筋交い）で、掘れる土であることが一目で分かるようにした。

## 高精細の作り方

- 2D: キャンバスを表示解像度（devicePixelRatio 込み、最大 3 倍）で描く。キャラクター・岩は毎フレームのベクター描画、土の層は面ごと・大きさが変わったときに表示解像度で 1 回だけ作る（粒の密度は 1 セルあたり一定）。4K でも画素の拡大はしない
- 3D: 地層のテクスチャは計算で生成（高画質 2048²、標準 1024²、床と天井は半分）。ミップマップ＋異方性 8。壁は辺を固定して面だけ波打たせた箱。凹凸は bump。接地影は丸い影の板、粉じん・破片は使い回しの小片 260 個
- UI: 2D・通常 3D は DOM（文字はにじまない）。VR はキャンバスの板（1m あたり 1100px）

## UI

暗い焦げ茶の板（rgba(22,15,12,.92)）、琥珀 #ffc93c の強調、ミント #5fe0b5（ポンプの照準）、朱 #ff7a3a。角丸 16〜24px。照準は「琥珀＝掘る／ミント＝ポンプ／灰＝届かない」。
