# AEGIS RELAY 仕様書

この作品は Claude（Claude Code のクラウドセッション）で制作しました。

## 0. この仕様書の位置づけ

依頼文（「スターフォース再構築・2D／3D VR 版」）の要件のうち、次の 2 点はご本人の判断で変更した。

| 依頼の内容 | 実際に採用したもの | 理由 |
|---|---|---|
| N-100 上の OpenCode＋Unity（C#） | **three.js＋WebXR（JavaScript）**。このリポジトリ（retro-games）の作法どおり | クラウドセッションから N-100 に届かない（Remote Control で共有されたフォルダが 0 件）。ご本人が「B（ここで今すぐ着手できる方式）」を選択 |
| 1984 年の作品の再現、原音に忠実な曲・効果音 | **同じジャンル・仕組みのオリジナル作品**。名称・機体・ステージ・曲・効果音はすべて新規 | 特定の既存作品の再現（名前を変えた場合も含む）と、その曲・効果音の再演奏・再合成はお引き受けしていないため |

このため、依頼文の「原作との対応表」「原音との比較」は作っていない。代わりに **「ジャンルの要素 → この作品での実装」** の対応と、この作品の採用値を記す。数値はすべて**この作品の独自設定**で、過去に合意した値でも、原作の実測値でもない。

公開タイトル: **AEGIS RELAY（イージス・リレー）**。タイトル画面・入口ページに「非公式のオリジナル作品」と明記している。

## 4. 画面の流れと操作

起動 → タイトル → あそびかた（4 ページ）→ プレイ ⇄ ポーズ（再開・設定・タイトルへ）→ ゲームオーバー → リザルト（リトライ／タイトル）。

| 操作 | キーボード | ゲームパッド | タッチ（iPad） | Quest 3 |
|---|---|---|---|---|
| 移動 | 矢印 / WASD | 左スティック / 十字キー | 左半分の浮きスティック | 左スティック |
| 射撃 | Space / Z | A（南）・X（西）・RT | 右下の FIRE（押している間） | 右トリガー |
| 決定 | Enter / Z | A | タップ | A、またはレーザー＋トリガー |
| 戻る | X / Backspace | B / Select | 「戻る」 | B |
| ポーズ | Esc / P | Start | 右上の II | B / Y、HUD の「II メニュー」 |

- 自動連射（補助）は設定またはタッチのボタンで切り替え。使ったプレイの記録は「補助」の別枠に入る。
- デバッグ（`?debug=1`。I 無敵 / N 次のエリア / C コア前へ、`&inv` 最初から無敵）を使ったプレイは記録しない。
- フォーカスを失う・タブが隠れる・パッドが抜ける・XR の入力が変わる → 入力をすべて離した扱いにする。

## 5. 2D と 3D の関係

- ルールは `shared/sim.js` の 1 つだけ。2D（`play2d/`）と 3D（`play3d/`）は表示と入力だけを持つ。
- 判定は盤面の 2 次元座標だけ。3D の高さ（空の物体は地上の 20u 上）、揺れ、戦域の傾き、頭の位置は判定に入らない。
- 3D の戦域は盤面の長方形で切り抜いた「窓の中のジオラマ」。星空と奈落の星雲は切らない。
- 3D の視点: 通常画面は約 41° で見下ろす固定カメラ。VR は座位で、戦域（幅 0.82m）を目の高さ（1.2m 基準）より 0.5m 下・1.2m 先に置く。頭の動きは視点だけに反映する。カメラの強制回転・ロール・揺れは使わない。
- 戦域の距離・高さ・傾き・大きさは設定で変えられる。再センタリングは VR 内の設定メニューから行う（システムのボタンは必要ない）。

## 6. 画質の設定

| 設定 | 2D（Canvas） | 3D 通常画面 | 3D VR |
|---|---|---|---|
| 自動（初期値） | 表示の実寸×DPR から開始。50fps 未満が 2 秒続くと 0.85 倍ずつ下げる（下限 0.5） | DPR（上限 2）から同じ方式で下げる（下限 0.6） | 描画バッファ 1.0 倍、フォビエーション 0.4、90Hz |
| 大画面高精細 | 実寸×DPR（上限 3） | DPR（上限 3） | 1.2 倍、フォビエーション 0.2、90Hz |
| Quest 高画質 | 実寸×DPR | DPR（上限 2） | 1.0 倍、フォビエーション 0.4、90Hz |
| 軽量 | 約 1 倍 | 1 倍、爆発の粒を半分 | 0.8 倍、フォビエーション 1.0、72Hz |
| 手動 | 描画倍率 0.5〜2 | 同左 | 描画バッファの倍率に使用 |

画質の自動調整で変わるのは解像度だけで、敵の数・判定・得点・難度は変えない。下げ方は一方向のみで、上げ下げを繰り返さない。
