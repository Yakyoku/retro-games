# ART_REFERENCE — キャラクターと美術

## 方針（依頼からの変更）

依頼は「1983 年アーケード版の主人公・敵・動作を基準に、当時のタイトーの表現を踏襲」だったが、既存作品のキャラクター造形の再現は行っていない。
したがって **原作の公式画像・映像との比較は行っておらず、「原作らしさ」の検証結果も無い**。参照したのは「1980 年代前半のアーケードの人物表現の一般的な性質」だけである:

- 少ない色数で、人物どうしを配色の塊で見分けられる（主人公＝紺と橙、敵＝えんじと灰）
- 横から見て輪郭がはっきりした、頭・胴・脚の比率が分かりやすい体形
- 歩く・構える・しゃがむ・跳ぶ・倒れるが、静止画でも区別できる大きな姿勢差

## 主人公（エージェント「KITE」と制作上呼んだ）

- 紺のロングコート（腿の中ほどまで）・濃紺のズボン・黒の靴・黒い手袋
- 橙のマフラー（2D では揺れる 5 節、3D では首元の輪＋後ろへなびく 3 節）。遠目でも主人公と分かる印
- 黒の短髪（横分け・前髪）・肌色の顔（目・眉・鼻・耳）
- 銀色の拳銃を片手で水平に構える
- 頭身はおよそ 7（身長 1.75m、頭の半径 0.125m）

## 敵（警備員）

| 型 | 見た目 | 行動 |
|---|---|---|
| 0 | えんじの制服・灰色のヘルメット・白いバイザー | 立って撃つ |
| 1 | 型 0 ＋ 黄色の腕章 | 低い弾も撃つ。撃たれそうになるとしゃがむ |
| 2 | 暗いえんじ・濃灰のヘルメット・灰色のベスト・琥珀色のバイザー | 遮蔽物の陰で待ち、立って撃つ |

- 構えるとバイザーが橙→赤に光る（撃ってくる合図。色だけでなく、銃を水平に構える姿勢も変わる）。低い弾の構えはしゃがみ姿勢＋銃口の三角

## 2D と 3D で同じ人物にするための工夫

- 姿勢は共通の関数（`shared/art/pose.js`）。関節位置を 2D は線と面で、3D はカプセル・回転体・球で描く
- 脚は 2 関節 IK で足先を地面に置く。歩幅は移動距離から決まる（位相 π = 0.8m）ので足が滑らない。床への埋まりも起きない
- 銃は手前の手の前腕の向きに固定（手から離れない）
- 配色は `shared/art/palette.js` を両方で使う

## 資料で確認した特徴と、補った部分

- 確認した資料: なし（上記のとおり原作資料は使っていない）
- すべて創作: 背面（髪・ヘルメットの後ろ）、側面、コートの立体形状、マフラー、顔の部品

## 背景

- 夜の都市（星・月・窓明かりのビル群）、ビルの内装は棟ごとに配色を変えた（オフィス = 暖色の木、研究 = 青緑、警備 = 灰緑と赤）
- 赤いドアは色＋書類マーク＋上の三角の旗で区別、回収後は青緑＋チェックマーク（形でも区別）
